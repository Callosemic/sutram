## Description
This update introduces auto-resizing and borderless capabilities to textarea inputs, expands card detail rendering slots, exposes explicit disabled states on async buttons, and propagates flush layout properties through store input bindings.

### Key Changes Implemented
* **Auto-Resizing & Borderless Textarea (`sutram/js/inputs.js`)**:
  * Added `autoSize`, `maxHeight`, `minRows`, and `borderless` properties to `SutramTextarea`.
  * Implemented DOM height recalculation decoupled from Lit's render cycle using `requestAnimationFrame` and `IntersectionObserver`.
  * Added `:host([flush])` margin suppression rule and global ResizeObserver benign warning handler.
* **Card Detail & Slot Expansion (`sutram/js/primitives.js`, `yenvui/js/card.js`)**:
  * Added `detailPrefix` and `detailSuffix` properties to `YenvuiCard` and `SutramCard`.
  * Added `<slot name="detail">` to permit custom slotted detail elements inside cards.
  * Added mobile container query rule `@container (max-width: 480px)` to hide `.card-detail-main` on narrow screens.
* **Async Button Disabled State (`sutram/js/primitives.js`, `yenvui/js/async-btn.js`)**:
  * Exposed `disabled` property on `YenvuiAsyncBtn` and `SutramAsyncBtn`.
  * Guarded click handler to prevent event execution when disabled.
* **Store Input Flush Propagation (`sutram/js/sdk.js`)**:
  * Updated `bindStoreInput` helper to accept `flush` option and forward `?flush=${flush}` attribute to all form input primitives.

## Notes / Execution Log
All updates strictly adhere to pure ES module standards, UDF state isolation, automated lifecycle cleanup, and component boundary guardrails.
