## Description
* **Settings Engine Form Binding Standardizations (`sutram/js/primitives.js`)**: Upgraded `<sutram-generic-settings>` to replace raw HTML5 form controls (`<input>`, `<select>`, `<textarea>`, `<input type="checkbox">`) with standardized `<sutram-input>`, `<sutram-select>`, `<sutram-textarea>`, and `<sutram-toggle>` Web Component primitives, standardizing `@sutram-input-changed` event consumption.
* **Scrollable Entity Actions Bar (`sutram/js/primitives.js`)**: Added reflected `scrollable` boolean property and custom non-wrapping horizontal scroll styling to `<sutram-entity-actions>`, permitting entity action button trays to scroll cleanly in space-constrained layouts.
* **Fullscreen Modal Transparent Backdrop (`yenvui/js/modal.js`)**: Extended `:host([transparent])` modal backdrop rule to also apply to `:host([fullscreen])` elements, ensuring top-layer fullscreen dialog backdrops render cleanly without backdrop darkening or blur filter artifacts.

## Notes / Execution Log
All updates strictly adhere to zero-bundler ES module standards, UDF event isolation, and presentation chassis guardrails.
