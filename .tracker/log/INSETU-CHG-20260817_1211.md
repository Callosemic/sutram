## Description
Implemented new presentation primitives (`<yenvui-board>`, `<yenvui-column>`, `<yenvui-tag>`, `<yenvui-label>`), upgraded settings modal schema handling, eliminated CodeMirror initialization race conditions, and added top-layer modal self-healing.

### Key Changes Implemented
* **New Presentation Primitives (`yenvui/js/board.js`, `yenvui/js/label.js`, `yenvui/js/tag.js`)**:
  * Created `<yenvui-board>` and `<yenvui-column>` for container-query responsive multi-column layouts (`@container (max-width: 800px)`).
  * Created `<yenvui-label>` for standardized form field labels with E-Ink theme typography overrides.
  * Created `<yenvui-tag>` for compact status badges with semantic intent color mappings.
* **IoC Micro-Kernel & Wrapper Alignments (`sutram/js/primitives.js`, `sutram/js/inputs.js`)**:
  * Exported `<sutram-board>`, `<sutram-column>`, `<sutram-tag>`, and `<sutram-label>` wrappers.
  * Replaced raw HTML `<label>` elements in `inputs.js` with `<sutram-label>`.
  * Added `readOnly` property to `<sutram-textarea>` and option value selection logic (`?selected`) to `<sutram-select>`.
  * Upgraded `<sutram-generic-settings>` to ignore hidden schema fields (`type === 'hidden'`) and project manifest `settingsActions`.
* **Editor Boot Synchronization (`yenvui/js/editor.js`)**:
  * Awaited `loadLanguageExtension()` prior to `EditorView` instantiation to eliminate Lezer syntax parser race conditions during cold boot.
* **Top-Layer Modal Stack Self-Healing (`yenvui/js/modal.js`)**:
  * Added `bringToFront()` API method and self-healing stack bounce in `updated()` to keep modals at the top of `#top-layer` when re-opened.
* **Bootloader Fallback Output (`sutram/js/sutram-boot.js`)**:
  * Normalized error boundary render fallback outputs to clean plain text.

## Notes / Execution Log
All updates strictly maintain zero-bundler ES module standards, UDF state isolation, and presentation chassis compliance.
