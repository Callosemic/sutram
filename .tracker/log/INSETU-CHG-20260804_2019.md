## Description
Refined mobile gesture handling to support horizontally scrollable action trays within cards, selectively overriding Safari's edge-swipe back navigation.

### Key Changes Implemented
* **Action Tray Scrolling (`yenvui/js/card.js`)**: Updated CSS to support `flex-wrap: nowrap` and `overflow-x: auto` within `.actions-wrapper`, hiding scrollbars and enabling native touch scrolling. Increased default button padding for better touch targets.
* **Gesture Interception Refinement (`yenvui/js/card.js`, `yenvui/js/card-group.js`)**: Replaced blanket `e.preventDefault()` horizontal swipe blocks with boundary-aware logic. Interception now yields to native scrolling if the inner `.actions-wrapper` has available scroll distance in the swipe direction.
* **Touch Action Adjustments**: Changed `touch-action: pan-y` to `touch-action: pan-x pan-y` on card hosts to permit native horizontal scrolling of internal child elements.
* **Sutram Card Alignment (`sutram/js/primitives.js`)**: Updated `<sutram-card>` action slot containers to enforce `flex-wrap: nowrap` and `width: max-content` to inherit the new scrolling behavior.
