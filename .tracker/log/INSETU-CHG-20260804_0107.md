## Description
Integrated collapsible accordion deck physics for stacked card groups and refined visual card geometry tokens.

### Key Changes Implemented
* **Accordion Stacking Physics (`yenvui/js/card-group.js`, `sutram/js/primitives.js`)**:
  * Added `accordion` property configuration to `<yenvui-card-group>` and `<sutram-card-group>`.
  * Implemented dynamic accordion handles (`.more-handle`, `.collapse-handle`) to manage deck expansion state.
  * Integrated a `ResizeObserver` on slot children to dynamically compute pull-up margins (`marginTop`) and scale factors for stacked cards.
  * Added event-delegated click handling (`_handleStackClick`) to cleanly expand/collapse card decks while bypassing interactive card action buttons.
* **Card Style Refinements (`yenvui/js/card.js`)**:
  * Standardized `.card-wrapper` box-shadow styling using `--card-box-shadow`.
  * Adjusted `.card-body` vertical padding to optimize spatial density inside stacked accordion layouts.

## Notes / Execution Log
All DOM listeners and `ResizeObserver` instances attached during accordion deck initialization are cleanly disconnected in `disconnectedCallback()`, maintaining memory safety and event isolation.
