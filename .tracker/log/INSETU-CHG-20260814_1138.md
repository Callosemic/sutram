## Description
* **Bare Specifier Import Map Delegation (`yenvui/js/editor.js`, `docs/02_yenvui_blueprint.md`, `readme.md`)**: Replaced hardcoded `[https://esm.sh](https://esm.sh)` CDN URLs in `<yenvui-editor>` with environment-agnostic bare specifiers (`codemirror-core`, `@codemirror/lang-*`). Updated architecture documentation and README importmap guides to reflect host-delegated importmap resolution.
* **CodeMirror Writing Mode & Theme Compartments (`yenvui/js/editor.js`, `sutram/js/primitives.js`)**: Added `writingMode` boolean prop and CodeMirror compartment to `<yenvui-editor>` and `<sutram-editor>`, enabling serif typography, centered 720px max-width layout, and inline markdown formatting keybindings (`Mod-b`, `Mod-i`, `Mod-```). Added `themeConf` compartment for dynamic dark/light syntax theme updates.
* **Active Async Button Physics & Entity Actions (`yenvui/js/async-btn.js`, `sutram/js/primitives.js`)**: Added `active` boolean property to `<yenvui-async-btn>` and `<sutram-async-btn>` with high-contrast inset focus styling (including E-Ink overrides). Updated `<sutram-entity-actions>` to evaluate `act.isActive(entityData)` and project active state to button elements.
* **Collapsible Toggle Event Isolation (`yenvui/js/collapsible.js`, `sutram/js/primitives.js`)**: Added `e.stopPropagation()` on header click in `<yenvui-collapsible>` and target equality guards in `<sutram-collapsible>` to eliminate nested event bubbling desynchronization.
* **Extension Shortcut Registration (`sutram/js/sdk.js`)**: Extended `ExtensionRegistry.registerExtension` to parse `shortcuts` declarations and enhanced `registerShortcut` with metadata tracking in `_shortcutMeta`.

## Notes / Execution Log
All updates adhere to zero-bundler ES module standards, UDF event isolation, and presentation chassis compliance.
