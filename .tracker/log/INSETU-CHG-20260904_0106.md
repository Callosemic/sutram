## Description
* **Offline Micro-Kernel Architecture**: Introduced `sutram/js/offline.js` (`SutramDB`, `OfflineHttpProvider`, `NetworkHysteresisManager`, `OutboxReconciler`), `sutram/js/sw-core.js` (abstracted service worker core with offline HTML fallbacks), `sutram/js/client.js` (`SutramDataClient`, `HttpProvider`), and `EnvironmentStore` in `sutram/js/sdk.js`.
* **Offline Visual Degradation**: Updated `sutram/js/app_shell.js` to strip primary and sub-navigation tabs when offline unless marked as offline-capable. Updated `SutramAsyncBtn` in `sutram/js/primitives.js` to detect offline state and render read-only `🚫 Offline` state when appropriate.
* **Metronome Visibility Backoff**: Updated `ExtensionRegistry.startMetronome()` in `sutram/js/sdk.js` to replace 100ms `setInterval` with a `setTimeout` loop and `visibilitychange` listener that backs off to 60s when document is hidden to conserve mobile battery.
* **CodeMirror Ephemeral Word Count**: Added `sutram/js/wordcount.js` CodeMirror 6 plugin for ephemeral word count decoration widgets (`{{wordcount_start}}`, `{{wordcount_stop}}`, `{{wordcount_all}}`, `{{wordcount_sum}}`) and auto-closing tag injection. Integrated into `SutramEditor`.
* **Card Action Tray Auto-Resolution & Linter Enforcement**: Updated `SutramCard` to automatically resolve entity actions and slotted actions via `_hasResolvedActions()`. Added linter check `BANNED_HAS_ACTIONS_ATTRIBUTE` in `tests/sutram_consumer_linter.py` to deprecate explicit `has-actions` attribute.
* **yenVUI Accordion Deck Physics**: Updated `yenvui/js/card-group.js` with top collapse handles (`.collapse-handle.top`), dynamic `clipPath` calculations, top card z-index scaling, and `Expand N nested item(s)` handle labels.
* **yenVUI Layout & Modal Enhancements**: Updated `yenvui/js/board.js` and `yenvui/js/column.js` with 3-column grid container queries (`@container`). Updated `yenvui/js/editor.js` to isolate CodeMirror container DOM mounting in Shadow DOM (`<div id="cm-container">`). Updated `yenvui/js/modal.js` to dynamically hide footer container (`_hasFooter`) when no elements are slotted.
* **Contract & Index Alignment**: Added `docs/yenvui_contracts.md` defining yenVUI interface contracts and CSS intent tokens. Updated `CODE_INDEX.md` descriptions.
