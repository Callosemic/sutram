## Description
* **Accordion Stack Click Guard (`yenvui/js/card-group.js`)**: Updated `_handleStackClick` in `<yenvui-card-group>` to return early when `_childCount <= 1`. This prevents redundant click capture, event propagation halting, and expand/collapse state toggling when a card group contains only one or zero child cards.
