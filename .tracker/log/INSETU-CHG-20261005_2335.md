## Description

* **Micro-Kernel Extraction & `SutramContextMixin`**: Refactored `sutram/js/sdk.js` into `sutram/js/sutram_sdk.js`. Introduced `SutramContextMixin` to supply UDF store subscriptions, global listener registration, and managed interval teardowns to any base LitElement class.
* **Direct Class Inheritance in Primitives**: Simplified `sutram/js/primitives.js` components (`SutramBtn`, `SutramAsyncBtn`, `SutramCard`, `SutramModal`, `SutramWindow`, `SutramCollapsible`, `SutramPill`, `SutramFilterGroup`) by extending `Yenvui*` components directly via `SutramContextMixin`, eliminating duplicate wrapper DOM tags and nested Shadow DOM boundaries.
* **Grid-Constrained Spatial Windows**: Converted `<yenvui-window>` and `<sutram-window>` from absolute screen pixel coordinates (`x, y`) to spatial column anchors (`anchorCol`) and multi-column spans (`span`), dynamically bound to the spatial layout capacity.
* **Unsaved Buffer Protection & DOM Pool Capacity**: Added `_enforceCapacity` (25 node limit) to `SutramDOMPool` in `sutram/js/projection_engine.js` and added `_safeEvict` confirmation checks in `<sutram-app-shell>` to protect uncommitted file buffers prior to eviction.
* **Responsive Scroll View Primitive**: Added `<yenvui-scroll-view>` / `<sutram-scroll-view>` container (`yenvui/js/scroll-view.js`) with container-query responsive edge padding.
