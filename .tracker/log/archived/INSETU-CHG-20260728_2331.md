## Description
Initial release of the Sutram Micro-Kernel, declarative UI layout router, state container factories, and utility algorithms.

### Resolution Summary
* **`sutram/js/sdk.js`**: Implemented `createSutramStore`, `bindStoreInput`, `SutramElement` base component with automated lifecycle teardowns, and `ExtensionRegistry` event and slot bus.
* **`sutram/js/app_shell.js`**: Implemented `SutramAppShell` for dynamic tab layout synthesis, custom element caching, and sub-navigation action rendering.
* **`sutram/js/shared_styles.js`**: Established design tokens and styling primitives for Dark, Light, and E-Ink themes.
* **`sutram/js/shortcuts.js`**: Created context-aware keyboard shortcut router (`initShortcutRouter`).
* **`sutram/js/poller.js`**: Implemented `createJobPoller` with retry controls and 401 auth handling.
* **`sutram/js/utils.js`**: Built algorithmic utilities (`fuzzyFilterObjects`, `normalizeAccentText`, `debounce`, `slugify`, `copyToClipboard`).
* **`sutram/build_matrix.json`**: Defined vendor deployment paths for `insetu` and `axoneme-sdk`.
* **`sutram/CODE_INDEX.md`**: Documented directory operational roles.
