## Description
Integrated stacked visual layout variants for card groups and introduced standardized time manipulation algorithms.

### Key Changes Implemented
* **Card Group Stacking (`yenvui/js/card-group.js`, `sutram/js/primitives.js`)**: Added `stacked` property configuration to `yenvui-card-group` and `sutram-card-group`. Introduced `_applyStackedZIndex` slot orchestration to inject localized CSS tokens (`--card-border-top`, `--card-margin-bottom`, etc.) into child elements to simulate overlapping depth and continuous borders.
* **Card Rendering Support (`yenvui/js/card.js`)**: Updated `yenvui-card` CSS to accept dynamically injected stacking properties. Added `.top-shadow` overlay to support gradient depth between overlapping cards.
* **Time Utilities (`sutram/js/utils.js`)**: Built `timeAgo` for relative time string calculation (e.g., "5 minutes ago") and `formatDate` for locale-aware standard timestamp output.

## Notes / Execution Log
Diffs rigorously adhere to pure CSS variable token orchestration for slot children rather than mutating child Shadow DOM boundaries directly, maintaining component boundary safety.
