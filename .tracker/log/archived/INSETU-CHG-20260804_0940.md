## Description
This update refines micro-kernel module caching, extends settings schema capabilities, isolates selection interaction targets, and aligns dropdown and tab header presentation mechanics.

### Key Changes Implemented
* **Micro-Kernel Module Caching (`sutram/js/sdk.js`)**: Updated `ExtensionRegistry.loadBatches()` to pin version query parameters to `window.SUTRAM_BOOT_TS` instead of `Date.now()`, enforcing session-level module cache consistency across dynamic batch loads.
* **Settings Schema Action Fields (`sutram/js/primitives.js`)**: Extended `SutramGenericSettingsModal` to support `action` field types, rendering `<sutram-async-btn>` elements that dispatch `sutram-settings-action` custom events returning asynchronous promises.
* **Presentation Primitive Refactoring (`sutram/js/primitives.js`)**: Refactored `SutramFilterDropdown` to inherit directly from `YenvuiFilterDropdown` rather than wrapping it in a LitElement, reducing DOM wrapper overhead.
* **Background Poller Diagnostics (`sutram/js/poller.js`)**: Streamlined 404 response handling in `createJobPoller` to emit explicit context shift error messages without unnecessary response cloning.
* **Accordion Card Deck Physics (`yenvui/js/card-group.js`)**: Added `.selection-gutter` to the action click exemption list in `YenvuiCardGroup` to prevent selection toggling from expanding or collapsing stacked card decks.
* **Filter Dropdown Elevation (`yenvui/js/dropdown.js`)**: Adjusted `YenvuiFilterDropdown` panel `z-index` to 2000, aligning it with context menus and preventing stacking context clipping.
* **Tab Header Layout (`yenvui/js/tabs.js`)**: Added `position: relative` to `.tabs-header-wrap` in `YenvuiTabs` for consistent absolute element positioning in header action slots.

## Notes / Execution Log
All updates strictly adhere to zero-bundler ES module standards, UDF state isolation, and component boundary guardrails.
