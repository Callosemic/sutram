## Description
Consolidated the Sutram IoC micro-kernel runtime into `sutram/` and integrated the complete `yenvui` edge-native presentation chassis.

### Key Changes Implemented
* **Sutram Kernel Consolidation**: Relocated `js/` modules to `sutram/js/` and architectural ADRs to `sutram/docs/adrs/`.
* **IoC Action Filtering**: Updated `sutram/js/sdk.js` with `getExtension` and `hasExtension` helpers, and enhanced `getEntityActions` with `showOnly` and `suppress` whitelist/blacklist controls.
* **yenVUI Presentation Chassis Integration**: Added `yenvui/css/theme-tokens.css` (Dark, Light, E-Ink tokens), `yenvui/docs/` standards and blueprint, and `yenvui/js/` component primitives (`async-btn`, `card-group`, `card`, `category-section`, `collapsible`, `dropdown`, `editor`, `filter-group`, `modal`, `pill`, `search-bar`, `selection-tray`, `status-bar`, `tabs`, `toast`, `toolbar`).
* **Primitives Refactoring**: Refactored `sutram/js/primitives.js` to wrap `yenvui` primitives and introduced `sutram-entity-actions` and `sutram-card` IoC broker components.
* **Build Matrix Schema Alignment**: Updated `build_matrix.json` to map `yenvui/css`, `yenvui/js`, and `sutram/js` output distribution pathways to downstream host applications.
