## Description
* **Domain Decoupling:** Purged hardcoded references to `window.inSetu` across the `sutram/js/sdk.js`, `app_shell.js`, `primitives.js`, and `sutram-boot.js` files[span_0](start_span)[span_0](end_span). Ensured the Sutram framework exclusively relies on its own `window.Sutram` global space, maintaining strict Inversion of Control parity[span_1](start_span)[span_1](end_span).
* **Offline LRU Caching & Mutability:** Enhanced `SutramDB` in `offline.js` to track `ts` (timestamps) for `vfs_cache` entries and implemented an LRU (Least Recently Used) `pruneCache` method[span_2](start_span)[span_2](end_span). Added `headers` and `collapseKey` support to outbox envelopes[span_3](start_span)[span_3](end_span).
* **Concurrency Resilience:** Upgraded `OutboxReconciler.drain` to utilize the Web Locks API (`navigator.locks`) to guarantee single-threaded outbox processing across multiple browser tabs[span_4](start_span)[span_4](end_span). Added Circuit Breaker capacity checks inside `OfflineHttpProvider` to reject non-essential background warming when storage hits 80% capacity[span_5](start_span)[span_5](end_span).
* **Duck-Typed Selection Physics:** Replaced hardcoded `yenvui-card` and `insetu-card` component tag checks inside `YenvuiCardGroup._getCardFromPoint` with property-based duck-typing (`tagName.includes('-') && 'selected' in el && 'disableSelection' in el`)[span_6](start_span)[span_6](end_span). This mathematically generalizes the swipe selection physics to any compliant custom element[span_7](start_span)[span_7](end_span).
* **Poller Routing:** Added immediate bypass resolution for the `offline_queue` dummy job ID inside `createJobPoller`[span_8](start_span)[span_8](end_span).
