## Description

* **Generational Mark-and-Sweep DOM Projection Pooling (`sutram/js/projection_engine.js`, `sutram/js/app_shell.js`)**:
  * Extracted projection node lifecycle caching out of `<sutram-app-shell>` into a modular `SutramProjectionPool` in `sutram/js/projection_engine.js`.
  * Implemented generational mark-and-sweep node retention via `beginPass()`, `resolve(componentTag, subId, props)`, and `commitPass()`, automatically sweeping unreferenced projection elements to allow browser garbage collection.
  * Added non-destructive projection identity migration via `pool.rekey(oldId, newId)` and extension DOM eviction via `pool.evictExtension(unloadedExt)`.
  * Delegated mobile viewport edge-swipe suppression to `YenvuiViewportGuard.install()`, eliminating duplicate touch listeners on `SutramAppShell`.
* **Debounced Store Persistence & Flush Barriers (`sutram/js/sutram_sdk.js`)**:
  * Throttled `localStorage` and `sessionStorage` serialization in `createSutramStore` using a 250ms trailing-edge debounce with dirty key tracking (`dirtyLocalKeys`, `dirtySessionKeys`).
  * Implemented `store.flushPersistence()` and hooked into `store.switchScope()` and `window` `pagehide` events to ensure clean persistence before context switches.
  * Added `StoreRegistry.flushAll()` and integrated it into `StoreRegistry.switchTenantScope()` to guarantee tenant isolation.
* **Lazy LRU Cache Buffering & Non-Blocking Readonly Transactions (`sutram/js/offline.js`)**:
  * Converted `SutramDB.getVFSBlob` to `readonly` IDB transactions, eliminating write-lock stalls during frequent cache reads.
  * Implemented an in-memory `_lruBuffer` (`Map`) flushing asynchronously to `manifest_cache.vfs_lru_index` via `requestIdleCallback`.
  * Updated `SutramDB.pruneCache` to flush pending LRU access records and sort candidate eviction entries using combined memory and index timestamps.
* **Worker Fuzzy Search Fast-Path (`sutram/js/utils.js`)**:
  * Added a synchronous execution branch in `SutramWorkerBroker.prototype.dispatch` for `FUZZY_SEARCH` tasks with fewer than 500 items, avoiding worker IPC overhead on small catalogs.
* **Presentation Hardening & Editor Echo Guards (`sutram/js/primitives.js`)**:
  * Enforced `overflow-x: hidden; overscroll-behavior-x: none; touch-action: pan-y;` on `<sutram-virtual-list>` to eliminate touch conflict on mobile viewports.
  * Added `_lastEmittedValue` tracking to `<sutram-editor>` during `yenvui-editor-changed` events.
  * Added declarative support for `headerActionComponent` and `menuStores` in sub-navigation tab projections.
