## Description

* **CodeMirror Viewport Preservation & Minimal Diffing (`yenvui/js/editor.js`)**:
  * Implemented `_applyMinimalDiff` to calculate character-level prefix and suffix boundaries between incoming store values and active editor buffers.
  * Replaced full buffer annihilation (`from: 0, to: length`) in `updated()` and `transformContent()`, preserving active selection anchors, cursor focus, and scroll viewport offsets across reactive updates.
  * Decoupled JIT language vendorization by routing language queries through `ExtensionRegistry.executeUIHook('sutram:vendorize-language', lang)` before checking `window.Sutram.vendorizeLanguage`.
* **Prose Writing Mode & Smart Typography Engine (`yenvui/js/editor.js`)**:
  * Implemented `proseSmartTypography` with syntax-tree code context guards (`isInCodeContext`) and transaction-isolated history (`isolateHistory`) for double-hyphen em-dash generation (`--` -> `—`) and triple-hyphen horizontal rule/frontmatter restoration (`---`).
  * Implemented `handleProseEnter` supporting automatic list continuation for task items (`- [ ]`, `- [x]`), bulleted lists (`-`, `*`, `+`), and numbered lists (`1.`, `2)`), clearing list markers automatically on empty items.
* **WebKit Auto-Inflation & Container Rescaling Guards (`yenvui/css/theme-tokens.css`, `yenvui/js/card.js`, `yenvui/js/shared_styles.js`)**:
  * Injected `-webkit-text-size-adjust: 100%` and `text-size-adjust: 100%` across universal resets (`*`), document body, and shared component styles to prevent iOS WebKit mobile font-size auto-inflation.
* **Virtual List Double-Virtualization De-Escalation (`yenvui/js/card.js`)**:
  * Parameterized intrinsic card dimensions using CSS custom properties (`--card-contain-intrinsic-size`).
  * Added container context overrides (`:host-context(lit-virtualizer)`, `:host-context(sutram-virtual-list)`) enforcing `content-visibility: visible` and `contain-intrinsic-size: none` to prevent layout collapse and height thrashing inside virtualized lists.
  * Explicitly initialized all component properties in the `YenvuiCard` constructor to guarantee deterministic object shapes during virtual DOM recycling.
* **Component Event Boundary Isolation (`yenvui/js/collapsible.js`)**:
  * Reconfigured `yenvui-collapsible-toggled` custom event dispatches to `bubbles: false, composed: false`, preventing nested accordion headers from leaking toggle events to parent container handlers.
* **Modal Close Action Modernization (`yenvui/js/modal.js`)**:
  * Replaced the text "Back" button with an accessible `<yv-icon name="x">` close trigger featuring danger-intent hover feedback, tooltips, and explicit ARIA labels.
* **Theme Token Compliance & E-Ink Polish (`yenvui/js/drop-zone.js`, `yenvui/js/selection-tray.js`, `yenvui/js/tabs.js`, `yenvui/js/card.js`)**:
  * Replaced hardcoded hex strings and color keywords across E-Ink overrides and active states with semantic CSS custom properties (`var(--intent-*)`, `var(--text-light)`, `var(--bg-deep)`).
* **Test Suite Unification (`yenvui/tests/`)**:
  * Removed deprecated monolithic `yenvui/tests/fitness_functions.py` and `.gitkeep` following migration of all checks into `sutram/tests/fitness/`.
