## Description

* **StoreRegistry Multi-Tenant Architecture & Transactional Scope Transitions (`sutram/js/sutram_sdk.js`, `sutram/js/app_shell.js`)**:
  * Established singleton `StoreRegistry` coordinating multi-tenant store lifecycle, active scope resolution, and storage scoping (`getScopedStorage`, `setScopedStorage`, `removeScopedStorage`).
  * Implemented transactional scope transition locking via `StoreRegistry.beginScopeTransition(targetScopeId)` and `StoreRegistry.endScopeTransition()`, broadcasting `sutram:scope-transition-start` and `sutram:scope-transition-end`.
  * Suppressed `ExtensionRegistry.compileLayout()` and canceled debounced layout compilation in `SutramAppShell` during active transitions to prevent intermediate re-rendering thrashes.
* **Epoch-Guarded Asynchronous Store Fetching & In-Memory Resets (`sutram/js/sutram_sdk.js`)**:
  * Added deep clone utilities (`_cloneInitialValue`, `_buildCleanBaseline`) to ensure pristine state resets across scope boundaries.
  * Wrapped store `fetch*` methods with automatic epoch guards (`_scopeEpoch`) and `coalescedAsync`, discarding in-flight network promises if the scope or store epoch advances prior to fulfillment.
  * Implemented `resetMemoryOnly()` on Zustand store instances to reset in-memory state cleanly without clobbering localStorage or sessionStorage.
  * Scope-stamped `sutram-evict-projection` listeners, ensuring projection eviction events are ignored if targeting another tenant scope.
* **Deterministic Three-Way Text Merge Engine (`sutram/js/utils.js`)**:
  * Added zero-dependency `threeWayMergeText(baseText, localText, remoteText)` with Longest Common Subsequence line diffing (`_computeLcsDiffHunks`) bounded by a $bLen \times tLen \le 250,000$ matrix size safeguard.
  * Integrated a Zombie-ACK fast path resolving clean merges when remote lines form an earlier contiguous subslice of local lines.
  * Preserved CRLF line endings when present in remote source buffers and returned clean boolean conflict indicators (`clean: false`).
* **Projection Rekeying & Cross-Window IPC Synchronization (`sutram/js/sutram_sdk.js`, `sutram/js/app_shell.js`)**:
  * Implemented `LayoutStore.rekeyProjection` to dynamically remap projection identities across pinned column arrays, active column states, column histories, global MRU focus history, open windows, and active popout window registries.
  * Dispatched `sutram-rekey-projection` custom events and broadcasted `rekey_projection` IPC messages across `_layoutBus` (`BroadcastChannel`).
  * Updated `<sutram-app-shell>` to update cached node keys in `_activeNodes` and URL location hashes without unmounting or re-instantiating DOM elements.
* **Declarative Extension Unloading & Lifecycle Signals (`sutram/js/sutram_sdk.js`, `sutram/js/app_shell.js`)**:
  * Implemented `ExtensionRegistry.executeUnload` incorporating active `AbortController` cancellation (`getSignal`), automatic layout slot restoration (`_baseLayoutSlots`), window dismissal, column projection unpinning, and store memory reset.
  * Handled `sutram-extension-unloaded` in `<sutram-app-shell>` by evicting cached DOM nodes and triggering layout re-render.
* **Contextual Sub-Tab Menus & Group-Scoped Bulk Selection Actions (`sutram/js/primitives.js`, `sutram/js/app_shell.js`)**:
  * Introduced `<sutram-subtab-menu>` element rendering action triggers and active selection badges in spatial column headers.
  * Dynamically aggregated bulk actions using `ExtensionRegistry.getAggregatableActions({ group: slotConfig.bulkActionGroup })` and bound reactively to `SelectionStore`, `EnvironmentStore`, and `slotConfig.menuStores`.
* **Presentation Primitives & iOS WebKit Hardening (`sutram/js/primitives.js`, `sutram/js/shared_styles.js`)**:
  * Added `<sutram-field-card>` with scope badge rendering (`workspace`, `repo`, `daemon`, `secure`) and refactored `<sutram-settings-form>` to consume it.
  * Added `<sutram-projection-window-controls>` managing "Pop Out" and "Dock In" actions.
  * Added `.keyFunction` property to `<sutram-virtual-list>` and applied `-webkit-text-size-adjust: 100%` alongside `--card-content-visibility: visible` to eliminate iOS WebKit text inflation and double-virtualization paint artifacts.
* **Pure Inversion-of-Control & Decoupling (`sutram/js/app_shell.js`, `sutram/js/offline.js`)**:
  * Removed hardcoded domain tab lists (`cronic`, `skills`, `practice`) from `SutramAppShell`, delegating metadata resolution to the `sutram:resolve-primary-tab-meta` UI hook with core fallback mappings.
  * Replaced `window.inSetu?.stores?.App` tab navigation mutations with the `sutram-projections-migrated` event.
  * Removed domain-specific `/fs/save` inspection from `offline.js`, and dispatched `sutram-outbox-item-synced` upon successful outbox drain.
