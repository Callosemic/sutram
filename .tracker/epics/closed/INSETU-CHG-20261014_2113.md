## Description

* **Kinetic Diff Viewer Presentation Primitive (`<yenvui-diff-viewer>`)**:
  * Implemented `<yenvui-diff-viewer>` in `yenvui/js/diff-viewer.js` supporting four layout modes: `auto` (container query responsive), `split-side`, `split-stacked`, and `interleaved`.
  * Integrated dual-pane synchronous scrolling with active scroll-source claim locking to eliminate scroll bouncing across side-by-side views.
  * Added desktop mouse kinetic drag-and-throw momentum scrolling with velocity calculation and exponential decay.
  * Implemented cross-pane hover synchronization with animated ghost carets reflecting active character columns across aligned diff hunks.
  * Added comprehensive high-contrast E-Ink styling overrides.
* **Tier 0 Intra-Line LCS Diff Utilities (`yenvui/js/diff-utils.js`)**:
  * Added zero-dependency `diff-utils.js` featuring token-level Longest Common Subsequence (LCS) alignment (`computeIntraLineTokens`) with dynamic programming memory limits ($m \times n \le 40000$) for minified lines.
  * Supported input formats: paired raw hunk strings (`searchStr`, `replaceStr`), Python `difflib.ndiff` streams, and unified diff formats.
  * Emitted synchronized dummy lines and intraline tokens for side-by-side and unified interleaved tracks.
* **Theme Observer Decoupling (`yenvui/js/editor.js`)**:
  * Replaced host-scoped `insetu:theme-changed` listener with agnostic `yenvui-theme-changed` event.
  * Added fallback `MutationObserver` on `document.body` for `data-theme` changes to trigger CodeMirror theme compartment reconfiguration.
* **Card Panning Click Shield (`yenvui/js/card.js`)**:
  * Suppressed `yenvui-card-clicked` custom event dispatches when horizontal swipe/pan gestures are active (`_isPanning`).
