## Description

* **Offline & Network Resilience**: Enhanced `OfflineHttpProvider` to cleanly handle `AbortError` without forcing offline state or enqueueing search mutations. Refactored `NetworkHysteresisManager` with a concurrency guard (`isChecking`) and a fast 2-second timeout burst verification loop before declaring network restoration.
* **Background Polling**: Updated `createJobPoller` in `sutram/js/poller.js` to intercept `AbortError` gracefully and exit cleanly on workspace swaps.
* **Settings Modal UX**: Implemented `_jsonBuffers` in `SutramGenericSettingsModal` (`sutram/js/primitives.js`) to buffer raw string input during object/JSON field editing, preventing cursor jumps and loss of input during intermediate typing.
* **Card Stale State**: Added `stale` reactive property to `<yenvui-card>` and `<sutram-card>`, applying styled visual feedback (`opacity: 0.65`, `filter: grayscale(0.3)`, dashed border) for outdated or dirty items.
* **Toast Top-Layer Stacking**: Updated `<yenvui-toast-container>` (`yenvui/js/toast.js`) to use native `popover="manual"`, eliminating backdrop overlay conflicts while re-promoting incoming notifications to the top of `#top-layer`.
