## Description

* **Native `<yv-icon>` Web Component Integration**: Introduced `<yv-icon>` micro-primitive in `sutram/js/sutram-boot.js` and replaced runtime Lucide DOM scanning (`window.lucide.createIcons`) across all `sutram` and `yenVUI` components, eliminating Shadow DOM mutation thrashing[cite: 1, 2].
* **Direct Lit Node Retention & DOM Pool Deprecation**: Deprecated `SutramDOMPool` in `sutram/js/projection_engine.js` in favor of direct Lit element lifecycle node retention maps (`_activeNodes`) in `sutram/js/app_shell.js`, reducing memory overhead and relying on native browser garbage collection[cite: 1, 2].
* **Virtualized List Primitive (`<sutram-virtual-list>`)**: Added `<sutram-virtual-list>` in `sutram/js/primitives.js` wrapping `lit-virtualizer` for high-performance rendering of large dataset collections[cite: 2].
* **CodeMirror Exception Shielding & Telemetry**: Added `EditorView.exceptionSink` in `yenvui/js/editor.js` to suppress internal plugin crashes, exposed scroll/cursor state helpers (`getCursor`, `setCursor`, `getScrollInfo`, `setScrollInfo`), and dispatched native `yenvui-editor-selection` and `yenvui-editor-scroll` events[cite: 1].
* **Card Stack & Accordion Physics Adjustments**: Refined accordion pull-up math, clipPath calculations, and bottom border-radius handling for stacked cards in `yenvui/js/card-group.js`[cite: 1].
* **Universal Hover Mechanics & Design Tokens**: Added `.yv-interactive-row` utility class to `yenvui/css/theme-tokens.css` with dark, light, and e-ink hover states, standardizing interactive row highlight mechanics across folder browsers and selector modals[cite: 1].
* **Store Hydration & Layout State Consistency**: Exposed `store.hydrateStore` in `createSutramStore`, updated `LayoutStore.unpinFromColumn` to preserve active tab selection fallback, synchronized subtab slot definitions during layout compilation, and triggered `onForceRefresh` on re-clicking active subtabs[cite: 1, 2].
