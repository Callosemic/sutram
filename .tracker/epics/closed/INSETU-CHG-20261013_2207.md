## Description

* **Universal Spatial Report Projection Primitive (`<sutram-report-projection>`)**: Added `<sutram-report-projection>` in `sutram/js/primitives.js` providing multi-tab output switching, monospaced scroll buffers, integrated `<sutram-entity-actions>` bound to `text_blob` staging, and async action button bindings for diffs, dry-runs, and log transcripts.
* **Singleton Web Worker Broker (`SutramWorker`)**: Introduced `SutramWorkerBroker` in `sutram/js/utils.js` and transitioned `<sutram-folder-browser>` and `<sutram-selector-modal>` from ad-hoc component-level Web Workers to a centralized thread broker with request multiplexing and synchronous main-thread fallbacks.
* **Layout Focus MRU Backstack & Lifecycle Eviction Protocol**:
  * Implemented global `focusHistory` and per-column MRU stacks (`history`) in `LayoutStore` (`sutram/js/sutram_sdk.js`) to guarantee deterministic focus fallbacks when tabs or windows are unpinned or closed.
  * Added `persistenceSchema.onEvict` support to `createSutramStore` and exposed `onProjectionEvicted` on `SutramContextMixin`, with eviction broadcasts deferred via `queueMicrotask`.
* **Rendering Performance via `content-visibility`**: Integrated `content-visibility: auto` and `contain-intrinsic-size` into `<yenvui-card>` and `<yenvui-collapsible>`, dynamically falling back to `visible` during interactive gestures, stacked modes, and drawer activations.
* **Bootloader Guardrail Refactoring**: Removed monkey-patching of `customElements.define` in `sutram/js/sutram-boot.js`, centralizing component error boundaries (`_isSafeConnected`, `_isSafeRender`) into the `SutramElement` class hierarchy.
* **Cross-Boundary Event Resolution**: Introduced `getEventPath(e)` and `getEventTarget(e, selector)` in `yenvui/js/physics.js`, replacing raw `e.composedPath()` invocations across all components.
* **Decoupled Telemetry & CodeMirror Dynamic Extensions**:
  * Replaced host globals in `yenvui/js/dropdown.js` with agnostic `sutram-status-update` event dispatching.
  * Added `@codemirror/lang-*` importmap resolution, JIT vendorization fallback, and `transformContent(transformFn)` API in `yenvui/js/editor.js`.
  * Sanitized button status feedback in `YenvuiAsyncBtn` and `SutramGenericSettingsModal` by replacing presentation emojis with native `<yv-icon>` glyphs.
