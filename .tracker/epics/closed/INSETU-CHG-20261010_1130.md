## Description
* **Dynamic Spatial Column Layout Ratios**: Introduced `layoutRatios` state to `LayoutStore` in `sutram/js/sutram_sdk.js` and implemented proportional column width/left positioning calculations (`getSpatialMetrics`) in `sutram/js/app_shell.js` and `sutram/js/drag-coordinator.js`.
* **Off-Main-Thread Search & Tree Building**: Extracted heavy computational logic (`fuzzyFilterObjects` and `buildFileTree`) into `sutram/js/workers/search-worker.js`. Integrated dedicated Web Workers into `<sutram-folder-browser>` and `<sutram-selector-modal>` to eliminate main-thread stutter during query filtering.
* **Light-DOM BEM Primitive Consolidation**: Consolidated atomic presentation primitive styles into `yenvui/js/shared_styles.js` and `sutram/js/shared_styles.js`. Converted `YenvuiBtn`, `YenvuiAsyncBtn`, `YenvuiPill`, `YenvuiTag`, `YenvuiLabel`, `SutramInput`, `SutramSelect`, `SutramTextarea`, and `SutramToggle` to Light-DOM rendering (`createRenderRoot() { return this; }`), avoiding Shadow DOM style duplication.
* **Theme Mutation Observer Decoupling**: Deprecated `observeTheme()` and `MutationObserver` subscriptions in `SutramElement` and `YenvuiBase`, delegating theme token reactivity entirely to CSS variables and `data-theme` attribute cascading.
* **Bootloader Optimization**: Streamlined Stage 1 bootloader in `sutram/js/sutram-boot.js` by removing redundant runtime manifest fetching while preserving component error isolation guardrails and `<yv-icon>` Web Component rendering.

## Notes / Execution Log
* Verified fluid 60fps gesture tracking during multi-column panning and window spatial constraint updates.
* Confirmed worker auto-termination on element unmount (`disconnectedCallback`) in `<sutram-selector-modal>` and `<sutram-folder-browser>`.
