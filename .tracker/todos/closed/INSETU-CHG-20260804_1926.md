## Description
Implemented strict validation for declarative UI layouts and introduced host-level execution predicates for extension UI hooks.

### Resolution Summary
* **\`sutram/js/app_shell.js\`**: Patched \`SutramAppShell._compileLayout\` to enforce strict existence validation of cached active sub-tabs against the active layout slots. This prevents UI lockups or empty renders when extensions dynamically unmount or workspace partitions change.
* **\`sutram/js/sdk.js\`**: Enhanced the \`ExtensionRegistry\` with \`setFilterPredicate\` and \`_filterPredicate\` logic. This brings UI Hook executions into parity with Metronome ticks, allowing host applications to dynamically suppress visual hook execution for inactive or out-of-scope extensions without requiring a full unregister/re-register cycle.
