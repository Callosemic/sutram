## Description

* **Versioned App Shell Build Staging & Atomic Cutover (`sutram/js/offline.js`, `sutram/js/sw-core.js`)**:
  - Implemented versioned build staging (`sutram-build-<buildId>`) alongside persistent metadata management via `sutram-meta` (`/__sutram_active_build__`, `/__sutram_pending_build__`).
  - Staged new application builds in the background during active runtime sessions without disturbing the running document's active cache, completely preventing lazy import mismatch and version skew.
  - Implemented `_promotePendingBuild()` in `sw-core.js`, promoting staged builds to active status strictly during top-level navigation requests.
  - Enforced captive-portal rejection (`_isCacheableBuildResponse` / `_isCacheableResponse`): HTTP 511, redirects, and non-200 responses are prevented from contaminating CacheStorage, preserving existing complete builds intact.
  - Implemented an origin-aware serving strategy: Cache-First on remote/tailnet origins when a complete build is cached for mobile resiliency; Network-First on loopback/localhost origins (`localhost`, `127.0.0.1`, `::1`) for instant developer reflection.
  - Added `X-Sutram-Revalidate: 1` header bypass in `sw-core.js` to ensure staging fetches directly query upstream servers.

* **Outbox Mutation Tracking & Cache Warmer Prefix Pruning (`sutram/js/offline.js`)**:
  - Extended `SutramDB.enqueueMutation` and `cacheOverlay` with `pendingMutations` and `deletedMutations` tracking, merging mutation sets across collapsed outbox entries via set unions.
  - Preserved mutation arrays during DLQ retry operations in `SutramDB.retryDeadLetter`.
  - Added `SutramCacheWarmer.size` and `SutramCacheWarmer.removeByPrefix(scopeId, urlPrefix)` for deterministic cache queue inspection and cancellation.

* **Form Input Value Synchronization & Event Containment (`sutram/js/inputs.js`)**:
  - Added model candidate validity retention in `SutramTargetBinding`: switching endpoints preserves the current model if valid within the candidate collection, preventing arbitrary selection drops.
  - Added `stopPropagation()` to child select and combobox events inside `SutramTargetBinding` and text input in `SutramComposer`.
  - Added `_syncInnerTextareaValue(val)` in `SutramComposer` to keep native `<textarea>` values in sync during slash-command absorption, trigger selection, and text edits.

* **Browser Identity Invariant & Zero-Dependency ESM Test Loader (`tests/unit/js_loader.mjs`, `tests/unit/test_sutram_registry.py`)**:
  - Created `js_loader.mjs` enforcing `globalThis.window === globalThis` and resolving `'sutram-chassis'`, `'sutram/*'`, and `'yenvui/*'` bare specifiers directly against repository sources.
  - Replaced brittle file copying and string substitutions in `test_sutram_registry.py` with direct Node execution via `--import={JS_LOADER_PATH.as_uri()}`.
  - Added unit test vectors for captive-portal rejection, build staging, and cache warmer prefix pruning.

* **Static Hardening (`tests/fitness/rules_sutram.py`)**:
  - Enforced `DETACHED_WINDOW_MOCK_BAN` static rule banning detached `globalThis.window = { ... }` object literal assignments across test suites.
