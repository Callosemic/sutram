## Description

* **Spatial Column Unit Constants & Self-Measured 720px Card Width Tiers (`yenvui/js/physics.js`, `yenvui/js/card.js`, `yenvui/js/card-group.js`, `sutram/js/sutram_sdk.js`, `sutram/js/app_shell.js`, `sutram/js/primitives.js`)**:
  - Exported `COLUMN_UNIT_PX = 360` and `WIDE_CARD_MIN_PX = 720` from `yenvui/js/physics.js` (and `SUTRAM_COLUMN_UNIT_PX` / `SUTRAM_WIDE_CARD_MIN_PX` from `sutram/js/sutram_sdk.js`), replacing hardcoded `360` literals in `SutramAppShell` and `LayoutStore`.
  - Added `ResizeObserver`-driven width tier detection (`_updateCardWidthTier`) to `<yenvui-card>`, reflecting `[wide-card]` at `>= 720px` and emitting `@yenvui-card-tier-changed`.
  - Rendered card actions inline on `[wide-card]` hosts while keeping the slide-over action drawer for `< 720px` cards, and removed legacy horizontal scrollbar panning from `.actions-wrapper`.
  - Updated `<sutram-card>` to mount `<sutram-entity-actions>` automatically when entering the wide tier or opening the drawer, and to close the narrow drawer when `@yenvui-action-confirmed` settles (`phase === 'settled'`) unless `keepDrawerOpen` is set.
* **Variant Sets, Split Buttons (`<sutram-variant-btn>`), & Device-Local Defaults (`sutram/js/sutram_sdk.js`, `sutram/js/primitives.js`)**:
  - Added `VariantDefaultStore` (`localSync: ['lastUsed'], scope: 'global'`) and `ExtensionRegistry` APIs (`registerEntityFamilies`, `resolveEntityFamily`, `registerVariantSet`, `getVariantSet`, `getLastUsedVariant`, `setLastUsedVariant`, `resolveDefaultVariant`, `_sortActionEntries`, `_collapseVariantSets`).
  - Enforced one-level nesting refusal for variant sets and action groups, device-local last-used variant persistence per `(entityType, setId)`, and family preference order fallback when a last-used variant does not match the current entity item.
  - Implemented `<sutram-variant-btn>` (`SutramVariantBtn`) pairing a width-reserved primary `<sutram-async-btn>` (`--variant-min-width`) with a sectioned `<sutram-dropdown>` split trigger.
  - Updated `<sutram-subtab-menu>` to flatten bulk `variant-set` entries into section headings and actionable menu items.
* **Fit-Then-Overflow Entity Action Broker (`sutram/js/primitives.js`)**:
  - Implemented `computeFitActionCount(containerWidth, buttonWidths, moreTriggerWidth, gapPx, hasGuaranteedOverflow)` and refactored `<sutram-entity-actions>` to measure available width via `ResizeObserver`, rendering fitting surfaced actions inline and overflowing remaining actions into a sectioned `more-horizontal` `<sutram-dropdown>`.
  - Prevented destructive (`intent: 'danger'`) actions from surfacing into primary action rows and ordered them at the end of their overflow section.
  - Updated `<sutram-selection-tray>` and `<sutram-report-projection>` to use fit-then-overflow `<sutram-entity-actions>`.
* **Managed Timeouts & 900ms On-Button Confirmation Holds (`yenvui/js/yenvui-base.js`, `yenvui/js/async-btn.js`, `yenvui/js/dropdown.js`)**:
  - Added `registerTimeout` and `clearManagedTimeouts` to `YenvuiBase` for automatic timeout cleanup on element disconnect.
  - Added `confirmHoldMs` (default `900`), section headings (`{ sectionHeading }`), and two-phase `@yenvui-action-confirmed` (`start` / `settled`) emissions to `<yenvui-async-btn>` and `<yenvui-dropdown>`.
* **CI, Static Linters, & Behavioral Unit Tests (`.github/workflows/ci.yml`, `tests/`)**:
  - Updated `.github/workflows/ci.yml` to pass `STACK_READ_TOKEN` explicitly.
  - Added `ALLOWED_ENTITY_ACTION_KEYS` and `iter_entity_action_objects` (`ENTITY_ACTION_UNKNOWN_KEY`) to `tests/sutram_consumer_linter.py` and expanded `HOST_DOMAIN_ISOLATION` in `tests/fitness/rules_sutram.py`.
  - Updated `globalThis.HTMLElement` in `tests/unit/js_loader.mjs` to inherit from `EventTarget` and added comprehensive Sprint U1 behavioral tests in `tests/unit/test_sutram_registry.py` and `tests/unit/test_consumer_linter.py`.
