## Description

* **Autonomous Chassis Barrel Export (`yenvui/js/index.js`)**:
  * Established canonical Layer 1 Presentation Chassis entrypoint declaring `CHASSIS_PROVIDER_META` (`{ name: 'yenvui', version: '2.0.0' }`).
  * Exported all 28 primitives defined in `REQUIRED_CHASSIS_PRIMITIVES` (`BaseElement`, `Btn`, `AsyncBtn`, `StatusBar`, `ToastContainer`, `Modal`, `Window`, `Card`, `CardGroup`, `CategorySection`, `Spinner`, `EmptyState`, `Board`, `Column`, `ScrubTrack`, `ScrollView`, `Dropdown`, `FilterDropdown`, `Collapsible`, `Pill`, `FilterGroup`, `Tag`, `Label`, `SearchBar`, `Toolbar`, `Tabs`, `DiffViewer`, `Editor`, `DropOverlay`, `DropTarget`, `SelectionTray`, `Input`, `Select`, `Textarea`, `Toggle`), alongside `sharedStyles` and `physics`.
* **Presentation Form Input Controls Extraction (`yenvui/js/inputs.js`)**:
  * Implemented pure, state-agnostic presentation input components: `YenvuiInput`, `YenvuiSelect`, `YenvuiTextarea`, and `YenvuiToggle`.
  * Standardized on Light DOM rendering (`createRenderRoot() { return this; }`) for seamless CSS BEM token cascading (`.yv-form-wrapper`, `.yv-input`, `.yv-select`, `.yv-textarea`, `.yv-toggle-wrapper`).
  * Encapsulated dynamic multiline auto-sizing (`minRows`, `maxHeight`), `IntersectionObserver` visibility calculation, and benign Chromium `ResizeObserver` loop error suppression in `YenvuiTextarea`.
  * Emitted isolated `yenvui-input-changed` custom events on value changes.
* **Upward Kernel Dependency Eradication (Layer 1 Isolation)**:
  * **`card.js` & `card-group.js`**: Replaced `:host-context(sutram-virtual-list)` with attribute selector `:host-context([data-virtual-list])`. Swapped button slot selectors for generic `::slotted([slot="actions"])`. Added public accessors `actionsOpen` and `hasActions`. Stamped host with `data-yv-card`. Added `@yenvui-card-actions-opened` event. Replaced explicit tag checks with suffix duck-typing (`tag.endsWith('-DROPDOWN')`, `tag.endsWith('-ASYNC-BTN')`, `tag.endsWith('-BTN')`, `tag.endsWith('-entity-actions')`).
  * **`dropdown.js`**: Decoupled `_notifyError` to dispatch local, composed `yenvui-action-error` events instead of broadcasting global `sutram-status-update` events.
  * **`editor.js`**: Removed upward references to `window.ExtensionRegistry` and `window.Sutram.vendorizeLanguage`, introducing a configurable `languageResolver` property and static `YenvuiEditor.languageResolver` fallback.
  * **`modal.js`**: Replaced explicit `sutram-async-btn[slot="footer"]` styling with universal `::slotted(:not(button)[slot="footer"])`.
  * **`physics.js`**: Replaced hardcoded `SUTRAM-WINDOW` and `SUTRAM-APP-SHELL` parent checks with `[data-spatial-boundary]`. Replaced `SUTRAM-VIRTUAL-LIST` check in `YenvuiViewportGuard` with generic shadow root inspection.
  * **`shared_styles.js`**: Purged all `sutram-*` custom element selector definitions, retaining strictly `yenvui-*` structural resets, and parameterized button alignment via `--btn-justify`.
