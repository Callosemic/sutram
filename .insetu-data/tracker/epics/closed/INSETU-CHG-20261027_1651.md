## Description

* **Bidirectional Top-Layer Popover Anchoring & Collision Flipping (`yenvui/js/dropdown.js`, `yenvui/js/physics.js`)**:
  * Implemented bidirectional vertical coordinate calculation in `anchorTopLayerPopover` with support for `direction: 'auto' | 'up' | 'down'`.
  * Added automated viewport bottom collision detection (`spaceBelow < menuHeight + 16 && triggerRect.top > spaceBelow`), dynamically flipping overlays to drop upwards (`popoverEl.style.bottom`) and clearing `top` to `'auto'`.
  * Exposed declarative `direction` property on `<yenvui-dropdown>` passing configuration directly to `anchorTopLayerPopover` and `syncTopLayerPopover`.
* **Icon-Only Button Margin Normalization (`yenvui/js/async-btn.js`)**:
  * Normalized icon margins in `<yenvui-btn>` and `<yenvui-async-btn>` by evaluating label presence (`hasLabel` / `hasText`).
  * Conditioned margin calculation to `hasLabel ? '6px' : '0'`, removing asymmetric trailing whitespace on icon-only buttons.
* **Form Textarea Minimum Height Tokenization (`yenvui/js/shared_styles.js`)**:
  * Parameterized `.yv-textarea` min-height using `var(--textarea-min-height, 38px)`, resolving layout conflicts with single-row auto-sizing textarea primitives.

## Notes / Execution Log
