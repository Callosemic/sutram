## Description

* **Pluggable Chassis Provider Contract & UI Adapter (`sutram/js/primitives.js`, `sutram/js/app_shell.js`, `sutram/js/drag-coordinator.js`, `sutram/js/shared_styles.js`, `sutram/js/sutram_sdk.js`)**:
  * Decoupled the Sutram micro-kernel from hardcoded relative import paths (`../../yenvui/js/*`), standardizing chassis imports on the bare specifier `'sutram-chassis'`.
  * Defined `REQUIRED_CHASSIS_PRIMITIVES` (28 presentation components) and introduced `validateChassisContract(chassisProvider)` for fail-fast boot verification.
  * Implemented `SutramUIAdapter` with an immutable `PASSTHROUGH_MAP` and `registerChassis()`, automatically declaring state-neutral custom element pass-throughs.
  * Standardized drag-and-drop drop targets in `drag-coordinator.js` via `sutram-drop-overlay` and `sutram-drop-target`.
* **Higher-Order Form Component Event Bridging (`sutram/js/inputs.js`)**:
  * Pruned redundant LitElement template and height calculation code by introducing `bridgeInputEvents(BaseClass)`.
  * Translated `yenvui-input-changed` events into `@sutram-input-changed` while maintaining clean propagation boundaries across `SutramInput`, `SutramSelect`, `SutramTextarea`, and `SutramToggle`.
* **Universal Wavefront & Hierarchy DAG Tree Component (`sutram/js/primitives.js`, `sutram/js/utils.js`)**:
  * Added `<sutram-dag-tree>` supporting both sequential/parallel wavefront execution stages (`stages`) and recursive hierarchical tree structures (`rootNode`, `nodes`).
  * Implemented `compileDagWavefronts(nodes, options)` in `sutram/js/utils.js` for topological sorting and wavefront compilation with cyclic termination safety.
* **Mustache Template Parameter Extraction and Interpolation Engine (`sutram/js/utils.js`)**:
  * Implemented `extractTemplateVariables(text, options)` and `interpolateTemplateVariables(text, values, options)` with macro support and fallback handling.
* **Layer 2 Sutram Headless State, Offline & Layout Kernel Public Entrypoint (`sutram/js/index.js`)**:
  * Added `sutram/js/index.js` aggregating all SDK state stores, offline synchronizers, projection engines, layout coordinators, primitives, and utilities into a unified entrypoint.
* **Domain Decoupling & Presentation Cleanliness**:
  * Removed `cleanCodeArtifacts` from `sutram/js/utils.js` to satisfy host domain isolation rules.
  * Parameterized `<sutram-selection-tray>` via `.trayTitle` and `.itemBadge`, purging hardcoded strings.
  * Migrated residual `<yenvui-*>` tags to `<sutram-*>` tags across `app_shell.js` and `primitives.js`.
  * Added `data-spatial-boundary` and `data-virtual-list` layout markers.
