## Description

* **Interactive Markdown Link Widgets & Navigation (`yenvui/js/editor.js`, `sutram/js/primitives.js`)**:
  - Added `enableMarkdownLinks` (default `true`) and `mdLinksConf` compartment to `<yenvui-editor>`.
  - Implemented `_buildMarkdownLinksExtension()` to decorate Markdown links outside code blocks and inline code with clickable `.cm-md-link-widget` (`↗`) triggers and `Ctrl`/`Cmd`-click handlers.
  - Dispatched `yenvui-editor-link-clicked` (`{ href, text, originalEvent }`) from `<yenvui-editor>` and bridged it to `editor-link-clicked` in `<sutram-editor>`.
* **Offline Micro-Kernel Vault, Telemetry & Atomic Read-Your-Writes Overlays (`sutram/js/offline.js`, `sutram/js/sw-core.js`)**:
  - Added `emitOfflineTelemetry` and `SutramDB.subscribeTelemetry` for structured `sutram:offline-telemetry` event dispatches.
  - Extended `SutramDB.enqueueMutation` with atomic `cacheOverlay` support (`cacheBlobUrl`, `cacheBlobContent`, `deletedCacheUrls`) to update or tombstone `vfs_cache` entries within the same IndexedDB `readwrite` transaction as outbox queueing.
  - Added `SutramDB.evictByPrefix`, `SutramDB.configure({ isTenantAgnosticUrl })`, and tenant-agnostic `default::` fallback lookup in `getVFSBlob` and `getCacheManifest`.
  - Upgraded `OfflineHttpProvider` with network-first GETs when online, `shouldCacheGet` predicates, HTTP `502`/`503`/`504` gateway fallback handling, `_verifyDaemonUnreachable()` active probing, and `sutram:offline-state-changed` event emissions.
  - Implemented `ensureSutramAppShellCached()` and `SutramCacheWarmer`, eliminated forced first-install reloads in `bootSutramServiceWorker()`, and updated `sw-core.js` to network-first caching with `/__sutram_app_shell__` fallback, HTML importmap/module discovery, and cross-origin bypass.
* **Functional Store Initializers, TDZ-Safe `urlParser`, & User Column Capacity (`sutram/js/sutram_sdk.js`, `sutram/js/app_shell.js`)**:
  - Enhanced `createSutramStore` to support functional initializers `(set, get, store) => state` and pass `(hash, hydratedState)` into `schema.urlParser`.
  - Added `userCapacity` and `setUserCapacity(cap)` to `LayoutStore` and synchronized viewport capacity clamping in `SutramAppShell` on resize and `sutram:scope-transition-end`.
* **Documentation, ADR-0031, & Unit Test Verification (`CODE_INDEX.md`, `docs/`, `tests/unit/test_sutram_registry.py`)**:
  - Added unit tests for functional store initializers, TDZ-safe `urlParser`, atomic `SutramDB.enqueueMutation` cache overlays, `evictByPrefix`, and `LayoutStore.setUserCapacity`.
  - Authored ADR-0031 and synchronized `docs/yenvui_contracts.md`, `docs/01_engineering_standards.md`, `readme.md`, and `CODE_INDEX.md`.
