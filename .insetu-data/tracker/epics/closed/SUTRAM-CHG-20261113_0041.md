## Description

* **Patience-Anchored Three-Way Text Merge Module (`sutram/js/merge.js`, `sutram/js/utils.js`)**:
  - Extracted `threeWayMergeText(baseText, localText, remoteText)` from `sutram/js/utils.js` into a dedicated `sutram/js/merge.js` module while maintaining a backward-compatible re-export in `sutram/js/utils.js`.
  - Implemented patience-sorting unique-line anchor matching (`_mergeUniqueAnchors`) to partition large files before running bounded LCS gap diffing (`_mergeLcsHunks`, `_MERGE_LCS_CELL_LIMIT = 250000`), preventing whole-file block fallbacks on sparse edits in long documents.
  - Added unambiguous adjacent hunk ordering (`_mergeGoesFirst`) so edits/deletions next to insertions merge cleanly while concurrent insertions at the exact same position trigger a conflict (`clean: false`).
  - Aligned implementation statement-for-statement with Python `akasa/merge.py` (`three_way_merge_text`).
* **Chassis Select Value Synchronization & Card Title Truncation (`yenvui/js/inputs.js`, `yenvui/js/card.js`)**:
  - Updated `YenvuiSelect` to synchronize `select.value` inside `updated()` rather than binding `.value` and `?selected` in `render()`, ensuring asynchronous `<option>` updates retain the bound selection.
  - Updated `.card-title` in `YenvuiCard` to enforce `white-space: nowrap`, `overflow: hidden`, and `text-overflow: ellipsis` for consistent single-row header truncation.
* **Service Worker Staging Integration Test & Merge Parity Vectors (`tests/unit/js/sw_core_staging.mjs`, `tests/unit/test_sutram_registry.py`, `CODE_INDEX.md`)**:
  - Added `tests/unit/js/sw_core_staging.mjs` exercising `ensureSutramAppShellCached` through `sw-core.js`'s real `fetch` listener on a non-loopback origin (`https://box.tailnet.ts.net`), verifying background build staging, active cache isolation prior to navigation, offline resilience, and navigation-gated promotion.
  - Added cross-language parity assertions in `tests/unit/test_sutram_registry.py` covering adjacent deletion/edit preservation, insertion-next-to-edit merges, concurrent same-point insertion conflicts, and 5,000-line sparse edits.
  - Synchronized `CODE_INDEX.md` with `.github/workflows/ci.yml`, `sutram/js/merge.js`, and `tests/unit/js/sw_core_staging.mjs`.
