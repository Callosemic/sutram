## Description

* **Ecosystem CI Battery Integration (`.github/workflows/ci.yml`)**:
  * Integrated the shared Callosemic multi-repository test battery (`Callosemic/insetu/.github/workflows/battery.yml@main`) triggered on push to `main`/`master` and workflow dispatch.
  * Configured concurrency cancellation (`ci-${{ github.repository }}-${{ github.ref }}`) to preserve pipeline capacity.
* **Architectural Fitness Rule Hardening (`tests/fitness/rules_sutram.py`, `tests/fitness/rules_yenvui.py`)**:
  * Added `SUTRAM_CHASSIS_IMPORT_ISOLATION` to enforce that Layer 2 Sutram micro-kernel modules import the active chassis strictly via `'sutram-chassis'` rather than hardcoded relative `'yenvui/'` paths.
  * Added `CHASSIS_PROVIDER_ISOLATION` to verify that Layer 1 yenVUI presentation components contain zero upward references to Sutram, `ExtensionRegistry`, or host-specific identifiers.
  * Tightened `CUSTOM_EVENT_NAMESPACE` in yenVUI to disallow `sutram-` or `sutram:` event prefixes, restricting emissions to `yenvui-` and `yv-`.
  * Expanded `HOST_DOMAIN_ISOLATION` leak regex to detect references to `Quickpack`, `cleanCodeArtifacts`, `cite_start`, `include_prompt`, and `plan_uri`.
  * Hardened `PYTHON_INLINE_IMPORT_SAFETY` in `rules_sutram.py` to evaluate `effective_name = alias.asname or alias.name`.
* **Consumer Linter Lit Expression Stripping (`tests/sutram_consumer_linter.py`, `tests/unit/test_consumer_linter.py`)**:
  * Implemented `strip_lit_expressions()` utilizing balanced brace depth tracking to replace `${...}` expressions with empty placeholders prior to markup evaluation.
  * Eliminated false-positive `SUTRAM_BUTTON_DECLARATIVE_LABEL_MANDATE` flags caused by arrow functions (`=>`) or comparison operators (`>`) inside button click bindings.
  * Added a dedicated unit test suite (`TestConsumerLinterButtonLabels`) validating icon-only buttons with arrow handlers, raw text children, and declarative labels.
* **Headless Node.js Unit Test Harness Expansion (`tests/unit/test_sutram_registry.py`)**:
  * Added `test_yenvui_chassis_provider_contract_and_ui_adapter_in_node` validating that `yenvui/js/index.js` fulfills all `REQUIRED_CHASSIS_PRIMITIVES` and `SutramUIAdapter.registerChassis()` correctly generates all pass-through `<sutram-*>` custom element classes.
  * Added `test_yenvui_diff_utils_and_sutram_ring0_algorithms_in_node` validating intra-line LCS tokens, unified diff parsing, DAG wavefront compilation, template variable extraction/interpolation, and file tree resolution.
  * Added `test_sutram_poller_shortcuts_and_network_hysteresis_in_node` testing sequential job chaining in `createJobPoller`, context-precedence routing in `initShortcutRouter`, and burst ping verification in `NetworkHysteresisManager`.
  * Cleaned up legacy test scope keys and projection component names to reference standard `sutram` identifiers.
* **Code Index & Readme Alignment (`CODE_INDEX.md`, `readme.md`, `pyproject.toml`)**:
  * Synchronized `CODE_INDEX.md` with new symbols (`strip_lit_expressions`, `bridgeInputEvents`, `validateChassisContract`, `SutramUIAdapter`, `YenvuiInput`, etc.) and mapped ADR ledger reorganization.
  * Expanded primitive tables in `readme.md` for both yenVUI and Sutram, updated zero-bundler import map documentation, and aligned project metadata in `pyproject.toml`.
