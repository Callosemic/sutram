## Description

* **Spatial Layout Design Token Standardization (`sutram/js/app_shell.js`)**:
  * Replaced fixed pixel dimensions with CSS custom property tokens: `--yv-rail-cell-width` (44px) for masthead action cells, `--yv-header-height` (44px) for masthead and column headers, `--yv-gutter-x` (12px) for header padding, and `--yv-icon-size` (14px) / `--yv-icon-gap` (8px) for sub-tab icons.
  * Added `z-index: 100` and `overflow: visible !important` to `.col-header` to guarantee popover and context menu overlays mounted in header action trays render outside the header box without clipping.
  * Harmonized the top utility row and right utility rail container with `align-items: stretch` and zero padding to ensure consistent visual alignment with masthead action rail cells.
* **Dropdown & Toolbar Prototype Un-Monkeypatching (`sutram/js/primitives.js`)**:
  * Dismantled the `enhanceDropdownClass` utility that monkey-patched `YenvuiDropdown.prototype` and `YenvuiFilterDropdown.prototype` lifecycle hooks with dynamic `<style>` injection, manual inline styling, and ancestor tree traversal.
  * Removed custom CSS overrides and the imperative `_toolbarAlignHandler` from `SutramToolbar`.
  * Restored pure Lit element class inheritance for `SutramToolbar`, `SutramDropdown`, and `SutramFilterDropdown`, enforcing strict alignment with the "Dumb Component" rule and zero runtime prototype pollution.

## Notes / Execution Log

* Verified that dropdown menus inside `SutramEntityActions` maintain autonomous positioning without requiring global prototype hijacking.
* Confirmed spatial column header and masthead action cells stretch consistently across Dark, Light, and E-Ink themes.
