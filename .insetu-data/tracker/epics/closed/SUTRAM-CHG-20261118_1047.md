## Description

* **Pluggable Backend Adapter Contract & Akasa Reference Adapter (`sutram/js/client.js`, `sutram/js/index.js`)**:
  - Standardized `REQUIRED_BACKEND_ADAPTER_METHODS`, `validateBackendAdapter()`, `BackendAdapterRegistry`, `registerBackendAdapter()`, `getBackendAdapter()`, `SutramBackendAdapter`, and `AkasaBackendAdapter`.
  - Implemented token storage persistence, single-flight 401 re-authentication, passive `X-Akasa-Build-ID` / `X-Sutram-Build-ID` build mismatch sniffing, per-scope `AbortController` cancellation, scope-guarded job polling, and SSE stream helpers.
  - Exported `client.js` from `sutram/js/index.js` and bound `HttpProvider`'s default fetch implementation via `globalThis.fetch`.
* **Adapter-Routed Offline Transport & Bounded App-Shell Revalidation (`sutram/js/offline.js`)**:
  - Updated `OfflineHttpProvider`, `NetworkHysteresisManager`, `ensureSutramAppShellCached`, and `SutramCacheWarmer` to route all network requests and health probes through `getBackendAdapter()` when registered.
  - Added single-flight deduplication and settled-build memoization in `ensureSutramAppShellCached`, `trustBuildId` short-circuiting, bounded worker-pool concurrency (`concurrency = 4`), `If-None-Match` ETag `304` revalidation, and `shellSyncDelayMs = 4000` deferral in `bootSutramServiceWorker`.
* **Composite Primitive Extraction & Chassis Refinements (`sutram/js/chassis_adapter.js`, `sutram/js/primitives.js`, `yenvui/`)**:
  - Extracted `SutramDagTree` and `SutramFloatingHud` into `sutram/js/chassis_adapter.js` with backward-compatible re-exports in `sutram/js/primitives.js`, and improved `<sutram-floating-hud>` drawer bounds and title truncation.
  - Added Base HTML Table Vacuum rules (`table`, `.dev-table`) to `yenvui/css/theme-tokens.css` and `yenvui/js/shared_styles.js`.
  - Added `?compact` mode and header title ellipsis truncation to `<yenvui-collapsible>`, preserved semantic intent strip rendering on non-selectable `<yenvui-card>` elements, tightened `<yenvui-stack>` row shrinking and `<yenvui-sidebar-layout>` responsive drawer sizing (`--yv-sidebar-width`), and removed duplicate `.close-btn:hover` CSS in `<yenvui-modal>`.
* **Verification & Documentation Parity (`tests/unit/test_sutram_registry.py`, `docs/`, `CODE_INDEX.md`)**:
  - Added `test_sutram_backend_adapter_contract_and_offline_transport_in_node` and synchronized `CODE_INDEX.md`, `docs/01_engineering_standards.md`, `docs/yenvui_contracts.md`, and `docs/ADR_INDEX.md` (ADR-0033).
