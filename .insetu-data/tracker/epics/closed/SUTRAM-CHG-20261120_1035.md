## Description

* **Canonical Column Band Engine & Named `yv-band` Containers (`yenvui/js/physics.js`, `sutram/js/sutram_sdk.js`, `yenvui/js/window.js`, `yenvui/js/layout.js`, `sutram/js/app_shell.js`):**
  - Replaced scattered width breakpoints (`480px`, `520px`, `700px`, `720px`, `768px`, `1100px`, `45rem`) and `WIDE_CARD_MIN_PX` / `SUTRAM_WIDE_CARD_MIN_PX` with `COLUMN_UNIT_PX = 360`, `COMPACT_MAX_PX = 384`, `COLUMN_BANDS`, `BAND_QUERY`, `columnBandOf`, `columnCountFor`, `findColumnContainer`, `columnBandForElement`, and `observeColumnBand`.
  - Declared `container: yv-band / inline-size` on `.spatial-col`, `<sutram-app-shell>`, `<yenvui-window>` `.body`, and `<yenvui-sidebar-layout>` `.sidebar-rail` (`[data-band-container]`), and rendered `.spatial-col` dividers via `::after` so each column's `clientWidth` matches its exact layout share.
  - Unified column-count calculation across `SutramAppShell`, `LayoutStore.setUserCapacity`, and `LayoutStore` `urlParser` via `columnCountFor(width)`, and updated `canUseMultiWindowPopout()` to check `isCoarsePointer && columnBandOf(window.innerWidth).capability === 1`.
* **Band-Driven Layout & Compact Room Adaptation (`yenvui/js/card.js`, `yenvui/js/card-group.js`, `yenvui/js/collapsible.js`, `yenvui/js/board.js`, `yenvui/js/scroll-view.js`, `sutram/js/inputs.js`, `sutram/js/primitives.js`):**
  - Updated `<yenvui-card>` to derive `[wide-card]` from `observeColumnBand(this, ...)` (`capability >= 2`) rather than self-measuring its own width, and migrated all `@container` / `@media` rules and compact thresholds (`SutramSelectionTray`, `anchorTopLayerPopover`) to `BAND_QUERY` and `columnBandOf(w).compact`.
* **Fixed Tab-Menu Chevron & In-Place Active Tab Highlighting (`sutram/js/app_shell.js`, `sutram/js/sutram_sdk.js`):**
  - Moved the column tab switcher and category launcher dropdown to a dedicated `44px` `.tab-menu-trigger` chevron button, keeping inline tabs in stable order with in-place `.active` highlighting and `LayoutStore.movePinToFront` promotion when an off-screen tab becomes active.
* **Diff Viewer Wrapping, Unified First-Change Scroll, & `DiffViewStore` (`yenvui/js/diff-viewer.js`, `sutram/js/primitives.js`, `sutram/js/sutram_sdk.js`):**
  - Added `.wrap` (`'auto' | 'on' | 'off'`), a toolbar `Wrap` button (disabled in side-by-side mode), narrow-column auto-wrapping, and Unified mode scroll-to-first-change on `<yenvui-diff-viewer>`, persisted device-locally via `DiffViewStore` on `<sutram-diff-viewer>`.
* **Documentation, Fitness Enforcement, & Unit Verification (`docs/`, `CODE_INDEX.md`, `tests/`):**
  - Published `ADR-0036`, added `RAW_BAND_WIDTH_BAN` in `tests/fitness/rules_sutram.py`, updated `RESIZE_OBSERVER_CLEANUP` in `tests/fitness/rules_yenvui.py`, and expanded unit assertions in `tests/unit/test_sutram_registry.py`.
