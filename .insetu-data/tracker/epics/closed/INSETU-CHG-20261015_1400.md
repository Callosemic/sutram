## Description
* **Window Header Close Action (`yenvui/js/window.js`)**: Added explicit `.window-btn.close-btn` close button to the header of `<yenvui-window>`, stopping pointerdown propagation to prevent unwanted dragging or docking gestures, and dispatching a bubbling, composed `yenvui-window-close` custom event.
* **CodeMirror Markdown Tag Completion Defense (`yenvui/js/editor.js`)**: Sanitized dynamic Markdown language extension loading by filtering out `htmlCompletion` and `closeTags` from nested extensions to prevent unhandled Lezer autocomplete exceptions when users type raw HTML `<tags>` in Markdown mode.
* **Monospaced Font Ligature Suppression (`yenvui/css/theme-tokens.css`, `yenvui/js/editor.js`)**: Suppressed contextual font ligatures across `pre`, `code`, and all CodeMirror editor text blocks (`.cm-scroller`, `.cm-content`, `.cm-line`, and `baseTheme`) using `font-variant-ligatures: none` and `font-feature-settings: "liga" 0, "calt" 0`, guaranteeing 1:1 character-to-glyph column parity and eliminating multi-slash glyph merging.
* **Card Icon InnerHTML Elimination (`yenvui/js/card.js`)**: Removed legacy `.innerHTML` rendering for `<i` prefix icon strings in `YenvuiCard`, restricting icon rendering to declarative `<yv-icon>` Web Components and text node spans.
* **Automated Architectural Fitness Functions (`yenvui/tests/fitness_functions.py`)**: Added four automated fitness tests enforcing substrate invariants:
  * `test_window_close_button_compliance`: Verifies `YenvuiWindow` renders `.close-btn` and dispatches `yenvui-window-close`.
  * `test_editor_ligature_suppression_compliance`: Verifies `YenvuiEditor` enforces `font-variant-ligatures: none`.
  * `test_lit_template_no_html_comments_in_drag_coordinator`: Bans HTML comment tokens (`<!--`) inside Lit html`` templates in `drag-coordinator.js`.
  * `test_no_inner_html_in_substrate_compliance`: Enforces zero `.innerHTML` assignments across all substrate JavaScript modules in `yenvui/js` and `sutram/js`.
