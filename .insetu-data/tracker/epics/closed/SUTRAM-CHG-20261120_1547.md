## Description

* **Wide-Only Auto Side-by-Side Diffs (`yenvui/js/diff-viewer.js`, `docs/adrs/0036_column_bands.md`, `docs/yenvui_contracts.md`, `tests/unit/test_sutram_registry.py`):**
  - Updated `<yenvui-diff-viewer>` `mode="auto"` to render Unified (`interleaved`) with wrapping enabled below `wide` columns (`< 1080px`) and switch to side-by-side (`split-side`) only in `wide` columns (`>= 1080px`).
  - Unified view continues scrolling to its first changed line on open, and `Stacked` remains available as an explicit mode choice.
* **Off-Screen Tab Relocation in Column Tab Menu (`sutram/js/app_shell.js`, `tests/unit/test_sutram_registry.py`):**
  - Added `SutramAppShell._isColumnOnScreen(colId)` and updated `_buildColumnTabDropdownItems` so launching a tab that is already open in an off-screen column unpins it from the off-screen column and opens it in the clicked column, while tabs already on screen focus in place.
* **Selection Tray Token Estimates, Item Kinds, Selection Order, & Chip Labels (`sutram/js/primitives.js`, `docs/adrs/0015_sutram_decoupled_host_contracts_popout_shell_and_action_aggregation.md`, `docs/yenvui_contracts.md`):**
  - Added `formatTokenEstimate()`, `.chipLabel` (rendering `<chipLabel> (<count>)` instead of `<count> selected`), live kB + ~4-bytes/token header totals with `+` while any size is unknown, 1-based selection position numbering, and `sutram:resolve-item-kind` UI hook resolution on `<sutram-selection-tray>`.
* **Card Selection Indicators, Peeking Card Suppression, & Divided-Column Band Containers (`yenvui/js/card.js`, `yenvui/js/card-group.js`, `yenvui/js/layout.js`):**
  - Reflected `disableSelection` on `<yenvui-card>`, added hover and selected `✓` indicators on `.selection-strip`, capped `[wide-card]` `.actions-tray` width at `50%` so content keeps at least half the row, and suppressed peeking card text clipping via `--peek-content-opacity: 0` in collapsed accordion `<yenvui-card-group>` stacks.
  - Marked `<yenvui-sidebar-layout>` `.stage-pane` with `container: yv-band / inline-size` and `[data-band-container]` so cards in both panes of a divided column observe their own pane width.
* **Accessible Button Names, Numbered Quick-Jump Slots, & Test IDs (`yenvui/js/async-btn.js`, `sutram/js/primitives.js`, `sutram/js/app_shell.js`, `yenvui/js/card.js`, `yenvui/js/diff-viewer.js`):**
  - Added `accessibleName(host, label)` in `yenvui/js/async-btn.js` so icon-only `<yenvui-btn>` and `<yenvui-async-btn>` elements propagate host `title` / `aria-label` attributes onto their inner `<button>`.
  - Updated `<sutram-subtab-menu>` column jump slots to display `1`, `2`, and `3`, and added `data-testid` hooks across shell, tray, action, card, and diff viewer controls.
