## Description

* **SutramCombobox Searchable Input Primitive (`sutram/js/inputs.js`)**:
  * Implemented `<sutram-combobox>` extending `SutramElement` with keyboard navigation (`ArrowDown`, `ArrowUp`, `Enter`, `Escape`), typeahead filtering, and normalized item option models (`value`, `label`, `badge`).
  * Bound outside-click dismissal through `this.registerOutsideClick` for clean lifecycle management.
  * Emitted bubbling and composed `sutram-input-changed` custom events on option selection and text modification.
* **SutramTargetBinding Compound Endpoint/Model Control (`sutram/js/inputs.js`)**:
  * Implemented `<sutram-target-binding>` coupling `<sutram-select>` and `<sutram-combobox>` in a responsive 2-column grid collapsing to single-column on narrow viewports ($\le 520\text{px}$).
  * Normalized compound values across delimited strings (`endpoint::model`) and object contracts (`{ [endpointKey]: ep, [modelKey]: mod }`).
  * Supported dynamic model candidate resolution via functional delegate (`models: (endpointId) => [...]`).
* **Settings Engine Dynamic Schema Sourcing & Action Labels (`sutram/js/primitives.js`)**:
  * Added declarative support for `target_binding` schema fields in `<sutram-settings-form>`, delegating to `<sutram-target-binding>` and hooking into `this.optionResolver`.
  * Implemented dynamic `options_from` configuration on `select` fields, sourcing option arrays from sibling form data keys with customizable `value_key` and `label_key` properties.
  * Added fallback evaluation for action buttons accepting `field.action_label` alongside `field.button_label` and `field.label`.
  * Ensured safe option selection fallbacks (`effectiveVal`) preventing blank selects when candidate collections mutate.
* **Field Card Scope Badge Element Optimization (`sutram/js/primitives.js`)**:
  * Replaced custom element `<sutram-tag>` instances with lightweight `<span class="scope-badge">` spans in `<sutram-field-card>`, decreasing Shadow DOM nesting overhead while preserving high-contrast semantic color-mix styling.
* **Shared Styles Reset Coverage (`sutram/js/shared_styles.js`)**:
  * Added `<sutram-combobox>` and `<sutram-target-binding>` to block-display resets and `[flush]` / `[inline]` zero-margin rules.
* **Public Micro-Kernel Barrel Export (`sutram/js/index.js`)**:
  * Exported `SutramCombobox` and `SutramTargetBinding` from the canonical Layer 2 public entrypoint.
* **Service Worker Localhost Cache Bypass (`sutram/js/sw-core.js`)**:
  * Added `isLocalDev` detection (`localhost` or `127.0.0.1`), ensuring network fetches take precedence over stale cached assets during local developer sessions while preserving offline fallback capability when network transport is unavailable.
