## Description

* **Multi-Line Whole-Tag Consumer Analysis (`tests/sutram_consumer_linter.py`)**:
  * Implemented `iter_sutram_tags(text)` to yield complete `<sutram-*>` opening tag spans across line breaks.
  * Added balanced `${...}` interpolation expression skipping to prevent premature tag parsing termination on nested arrow handlers (`=>`) or comparison operators (`>`).
  * Migrated tag-level static checks (`SUTRAM_CARD_INTENT_TOKEN_MANDATE`, `SUTRAM_INLINE_STYLE_BAN`, `SUTRAM_SEMANTIC_PROP_MANDATE`, `UNIFIED_SCALE_TOKEN_MANDATE`) to whole-tag sweeps, ensuring properties on secondary lines are evaluated.
* **Component Reflection & Undeclared Binding Verification (`tests/sutram_consumer_linter.py`)**:
  * Added `load_declared_properties(sutram_root)` to reflectively resolve component properties and observed attributes across class bodies, inheritance chains, `SutramContextMixin`, chassis export aliases, and `PASSTHROUGH_MAP` entries.
  * Added `undeclared_bindings(tag, attrs, declared)` and the `SUTRAM_UNDECLARED_PROPERTY` rule, flagging bindings (`.prop`, `attr`, `?bool`) that do not match declared properties or reflected attribute names.
* **bindStore Initial State Hydration (`sutram/js/sutram_sdk.js`)**:
  * Resolved a state synchronization latency issue in `SutramContextMixin.bindStore`: immediately applied the mapped slice from `currentStore.getState()` upon initial subscription rather than waiting for subsequent state mutations.
* **Declared Property Parity (`sutram/js/primitives.js`, `yenvui/js/card.js`)**:
  * Declared `optionResolver: { attribute: false }` in `SutramSettingsForm.properties` to support functional option delegates for compound target bindings.
  * Formally declared `filename: { type: String }` in `YenvuiCard.properties`, establishing parity between internal event payloads, update checks, and consumer linter reflection.
* **Consumer Linter Test Suite Expansion (`tests/unit/test_consumer_linter.py`)**:
  * Implemented `TestConsumerLinterWholeTags` covering multi-line scale tokens, undeclared properties (`.notAProperty`), boolean attribute reflection mismatches, and inheritance/mixin property resolution.
