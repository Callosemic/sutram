## Description

* **Root Viewport Physics Guard (`yenvui/js/physics.js`)**:
  * Introduced singleton `YenvuiViewportGuard` operating at the document capture phase to defeat iOS/iPadOS Safari hardware bezel edge-swipe history navigation (`UIScreenEdgePanGestureRecognizer`).
  * Enforced synchronous cancellation on extreme hardware bezels ($\le 20\text{px}$ and $\ge \text{viewportWidth} - 20\text{px}$), resolving deep scrollable ancestors, recording velocity samples, and preserving vertical scrolling.
  * Implemented synthetic `MouseEvent('click')` dispatch for non-movement taps in the bezel zone, restoring focus and trigger responsiveness on inputs, buttons, and custom controls.
  * Registered `<yenvui-viewport>` custom element providing zero-overhead declarative installation via `display: contents`.
* **60fps Kinetic Momentum Throw Engine (`yenvui/js/physics.js`)**:
  * Implemented `startKineticThrow(scrollEl, samples, { axis, decay })` with exponential decay ($0.94$ friction) for continuous pointer and touch momentum scrolling on horizontal and vertical scroll containers.
  * Bound cancellation routines on subsequent touchstart events and element unmounting.
* **Reentrant Body Scroll Locking (`yenvui/js/physics.js`)**:
  * Added reference-counted `acquireBodyScrollLock()` and `releaseBodyScrollLock()`, preventing premature restoration of `document.body.style.overflow` when overlapping dialogs, overlays, or gesture controllers mount concurrently.
  * Integrated lock management into `YenvuiGestureController`.
* **Physics Constants Token Dictionary (`yenvui/js/physics.js`)**:
  * Exported frozen `PHYSICS` configuration object standardizing bezel dimensions, axis locking limits, tap slop, and velocity thresholds.
* **Chassis-Wide Overscroll Containment & Gesture Standardization**:
  * Standardized `touch-action: pan-y;` and `overscroll-behavior-x: none;` across `card-group.js`, `card.js`, `scroll-view.js`, `tabs.js`, `shared_styles.js`, and `yenvui-base.js`.
  * Integrated velocity tracking and `startKineticThrow` into `YenvuiScrubTrack` with full lifecycle cleanup.
* **Theme Token Vacuum & Dead Style Cleanup**:
  * Pruned redundant high-contrast theme overrides in `category-section.js` and `search-bar.js`, delegating E-Ink rendering to global cascading CSS tokens.
