## Description

* **SutramTextarea Dynamic Auto-Height Boundary Calculation (`sutram/js/inputs.js`)**:
  * Implemented explicit minimum height clamping (`minPx`) calculated from `minRows` (`minRows * 22 + 16` for `minRows > 1`, defaulting to `38px`).
  * Addressed empty value handling (`!this.value`) by pinning layout height directly to `minPx` to avoid zero/arbitrary `scrollHeight` evaluation.
  * Enforced lower bound clamping via `Math.max(minPx, Math.min(textarea.scrollHeight + 2, this.maxHeight || 500))` on populated textareas, ensuring content does not collapse below configured minimum row geometry.
