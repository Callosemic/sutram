## Description

* **Headless Node.js Unit Test Harness Expansion (`tests/unit/test_sutram_registry.py`)**:
  * Implemented test method `test_sutram_combobox_target_binding_and_settings_schema_in_node` validating ADR-0028 form controls in an isolated Node.js environment.
  * Validated `<sutram-combobox>` option normalization across raw string arrays and structured metadata (`value`, `label`, `badge`, `id`, `name`, `detail`), typeahead text filtering, 60-item rendering truncation limit, keyboard navigation (`ArrowDown`, `ArrowUp` wrap-around, `Enter` selection commit, `Escape` cancellation), and outside-click dismissal.
  * Validated `<sutram-target-binding>` value normalization across delimited strings (`endpoint::model`) and structured objects (`{ endpoint, model }`, `{ provider, engine }`), functional model catalog resolution (`models: (endpointId) => [...]`), and composed `@sutram-input-changed` event emissions.
  * Validated dynamic `options_from` schema extraction and `effectiveVal` fallback clamping in `<sutram-settings-form>`, ensuring selected values gracefully clamp to available options when candidate collections change.
* **Consumer Linter Guidance Update (`tests/sutram_consumer_linter.py`)**:
  * Updated `SUTRAM_FORM_CONTROL_MANDATE` violation message in `run_consumer_lint()` to explicitly guide developers toward `<sutram-combobox>` and `<sutram-target-binding>` alongside standard form controls.
* **Architectural Code Index Synchronization (`CODE_INDEX.md`)**:
  * Added ADR-0028 (`0028_compound_target_binding_and_sw_dev_cache_bypass.md`) to the ADR ledger outline.
  * Mapped newly exported `SutramCombobox` and `SutramTargetBinding` classes under `sutram/js/inputs.js`.
  * Preserved Single Source of Truth architectural indexing across the micro-kernel directory tree.
