## Description

* **Selector Memoization & Equality Comparison**:
  * Implemented pure `shallowEqual` utility in `sutram/js/utils.js` supporting primitives, Arrays, Sets, Maps, and plain Objects.
  * Added `equalityFn = shallowEqual` parameter to `SutramContextMixin.subscribe` in `sutram/js/sutram_sdk.js`, preventing redundant LitElement re-renders when state updates yield structurally equal values across both direct and deferred store bindings.
* **Hierarchical Tree Building & Directory State Resolution**:
  * Refactored `buildFileTree` in `sutram/js/utils.js` into a robust node tree model (`id`, `name`, `type`, `fullPath`, `parentPath`, `children`).
  * Added `resolveDirectoryState` with directory-first sorting and `.gitkeep` filtering, updating `<sutram-folder-browser>` in `sutram/js/primitives.js`.
* **Aggregated Multi-Entity Action Staging**:
  * Added `ExtensionRegistry.getAggregatableActions` in `sutram/js/sutram_sdk.js` to compute cross-entity batch operations matching compound entity types (`typeA:typeB`).
  * Upgraded `<sutram-selection-tray>` in `sutram/js/primitives.js` to render aggregatable batch actions alongside legacy handlers and resolve item byte footprint via UI hooks.
* **Host Application Domain Decoupling**:
  * Decoupled `<sutram-app-shell>` and `<sutram-selection-tray>` from `window.inSetu` globals by delegating to `sutram:is-projection-dirty`, `sutram:resolve-route-hash`, and `sutram:resolve-item-size` UI hooks on `ExtensionRegistry`.
* **Popout Shell Projection Variant**:
  * Implemented `variant="popout"` property on `<sutram-app-shell>`, enabling standalone rendering of single-projection views driven by route hash parameters.
* **Legacy Slot ID Migration & Projection Parity**:
  * Added `pinMatchesSlot` helper and migration mapping in `_compileLayout` to seamlessly reconcile legacy un-scoped subtab IDs against scoped extension definitions (`extName:id`).
* **Hardware-Accelerated Drag Tracking & Auto-Aligning Dropdowns**:
  * Bound 3D transforms (`translate3d`) to `.drag-floater` in `sutram/js/drag-coordinator.js` for 60fps gesture tracking.
  * Added container collision detection in `SutramToolbar`, `SutramDropdown`, `SutramFilterDropdown`, and menu-bar action trays to auto-align menus to the right when near viewport boundaries.
* **Diff Viewer Presentation Primitive**:
  * Exported `<sutram-diff-viewer>` wrapping `YenvuiDiffViewer` in `sutram/js/primitives.js`.

## Notes / Execution Log
