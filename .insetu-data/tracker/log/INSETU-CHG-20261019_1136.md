## Description

* **Decoupled Settings Form Engine (`<sutram-settings-form>`)**:
  * Extracted configuration form rendering and validation from `SutramGenericSettingsModal` into an independent `<sutram-settings-form>` element in `sutram/js/primitives.js`.
  * Added repository scoping controls with automatic target detection, missing-scope alerts, and `sutram-settings-repo-changed` event dispatching.
  * Added field scope badges (`workspace`, `repo`, `daemon`, `secure`) and filter query searching across field titles, descriptions, and identifiers.
  * Introduced typed field handlers for `intent_map` (visual grid of uppercase semantic tokens), `string_list` (comma-separated arrays), `action` (delegated execution via `sutram-settings-action`), and buffered `json`/`object` textareas with live parsing.
  * Added secret masking (`••••••••`) with clear buttons and configured tags.
  * Refactored `SutramGenericSettingsModal` into a pure presentation dialog wrapping `<sutram-settings-form>` and `<sutram-async-btn slot="footer">`.
* **Extension Registry Configuration Option Hooks (`sutram/js/sutram_sdk.js`)**:
  * Implemented `getRepoConfigOptions()` and `getBucketConfigOptions()` on `ExtensionRegistry`, gathering declarative extension options filtered by active predicates and sorted by `.order`.
* **Native ESM Batch Loading Sanitization (`sutram/js/sutram_sdk.js`)**:
  * Removed the `?v=${bootTs}` query parameter from dynamic `import()` calls in `ExtensionRegistry.loadBatches()`, preserving browser import map specifiers and preventing module graph duplication.
* **`<yv-icon>` Style Observation & Recursion Guard (`sutram/js/sutram-boot.js`)**:
  * Added `style` to `YvIcon.observedAttributes` and introduced an `_updatingStyle` flag inside `_renderIcon()` to prevent cyclic re-entry when inline styles are modified at runtime.
* **Selection Staging & Cache Key Parity (`sutram/js/primitives.js`, `sutram/js/offline.js`, `sutram/js/utils.js`)**:
  * Updated `<sutram-selection-tray>` to toggle selections using `toggleKey = item.key || rawPath` and sanitized trailing slashes from item paths.
  * Added `folderpath` resolution to `SutramCard._getId()`.
  * Simplified `SutramDB._normalizeCacheKey` by removing redundant `vfs://` regex replacements.
  * Extended `cleanCodeArtifacts` in `sutram/js/utils.js` to convert `|` artifacts to pipe characters (`|`) within inline mathematical delimiters (`$ ... $`).
