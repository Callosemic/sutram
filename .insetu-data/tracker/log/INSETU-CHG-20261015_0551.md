## Description

* **Universal Spatial Geometry Tokens (`yenvui/css/theme-tokens.css`)**:
  * Established canonical CSS geometry variables: `--yv-utility-height` (38px), `--yv-header-height` (44px), `--yv-gutter-x` (12px), `--yv-rail-cell-width` (44px), `--yv-icon-size` (14px), and `--yv-icon-gap` (8px).
  * Harmonized spacing contracts across header rows, rail buttons, and navigation slots.
* **Top-Layer Popover Anchoring Engine (`yenvui/js/physics.js`)**:
  * Added `anchorTopLayerPopover(triggerEl, popoverEl, options)` supporting floating menu mode (`'menu'`) with auto-reversing horizontal alignment and full-width spatial column bounding (`'column-drawer'`).
  * Added `syncTopLayerPopover(triggerEl, popoverEl, isOpen, options)` to manage native `#top-layer` lifecycle via `popover="manual"`, `showPopover()`, and `hidePopover()`.
* **Dropdown & Filter Dropdown Popover Elevation (`yenvui/js/dropdown.js`)**:
  * Migrated `<yenvui-dropdown>` and `<yenvui-filter-dropdown>` to native HTML5 Popover elements (`popover="manual"`), escaping all parent `overflow: hidden` and `z-index` stacking context traps.
  * Added capture-phase `resize` and `scroll` listeners in `connectedCallback` with automatic repositioning and complete unbinding in `disconnectedCallback`.
  * Bound filter dropdown button dimensions and icon sizes to `--yv-rail-cell-width` and `--yv-icon-size`.
* **Toolbar Design Token Adoption (`yenvui/js/toolbar.js`)**:
  * Refactored `.toolbar-row` padding and height to reference `--yv-gutter-x` and `--yv-header-height`.

## Notes / Execution Log

* Verified that dropdown menus inside spatial headers and utility rails project above all neighboring panels without boundary clipping.
* Confirmed that capture-phase scroll handlers reposition popovers continuously during column and document scrolling.
* Validated that unmounting `<yenvui-dropdown>` or `<yenvui-filter-dropdown>` cleanly invokes `syncTopLayerPopover(..., false)` and disposes of all window event listeners.
