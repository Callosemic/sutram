## Description
* **CSS Mask-Image SVG Micro-Primitive (`yv-icon`)**: Replaced dynamic innerHTML SVG string parsing in `sutram/js/sutram-boot.js` with CSS Mask (`mask-image` / `-webkit-mask-image`) rendering backed by an in-memory Data URI cache (`_iconMaskCache`) and observed attribute synchronization (`name`, `stroke-width`). Added the canonical `construction` SVG icon sprite.
* **Spatial Drag HUD Coordinator & Preset Architecture**: Overhauled `<sutram-drag-coordinator>` in `sutram/js/drag-coordinator.js` from basic drop boxes into a full workspace Head-Up Display (HUD). Added dual mode-switching (`tab` vs. `window`), Pop-Out ejection staging (`zone="popout"`), Column targets, multi-column span presets (`span-1`, `span-2`, `span-3`), tab reorder tracking (`reorder-*`), and high-contrast E-Ink styling overrides.
* **Popout Shell Projection Routing & Capability Verification**: Added popout detection and routing within `<sutram-app-shell>` in `sutram/js/app_shell.js`, gating execution behind `allow_popout` and rendering a fallback placeholder for unsupported projections.
* **Custom Editor Resolution Registry**: Introduced `ExtensionRegistry.resolveCustomEditor(filepath)` in `sutram/js/sutram_sdk.js` to match file paths against extension-provided custom editor definitions, decoupling editor selection from domain-specific hardcodings.
* **Offline Cache Key Normalization & Write-Through Mutation**: Added `SutramDB._normalizeCacheKey` in `sutram/js/offline.js` to strip timestamp query parameters and normalize `vfs://` protocol schemas across `cacheVFSBlob`, `deleteVFSBlob`, and `getVFSBlob`. Implemented optimistic write-through caching on `/fs/save` POST mutations to guarantee read-your-own-writes consistency offline.
* **Service Worker Lifecycle & Cache Purge Utilities**: Exported `purgeSutramCaches()` and `bootSutramServiceWorker()` in `sutram/js/offline.js`, providing dynamic asset prewarming, controller transition handling, and deferred reloading during outbox synchronization.
* **Surgical DOM Mutation & InnerHTML Elimination**: Removed `.innerHTML` usage in `SutramGenericSettingsModal` (`field.description` text binding with `field.intent_legend` indicators) and in the `<sutram-app-shell>` element error boundary (`replaceChildren`). Added automated dirty state icon reflection in `SutramCard` (`construction` icon).
