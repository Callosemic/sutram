## Description
* **Floating Window Projection Layer:** Introduced `<yenvui-window>` and `<sutram-window>` allowing workspace entities to be detached from spatial columns into draggable, resizable native `<dialog>` layers. Bound to the updated `LayoutStore` windows array.
* **Tri-Level Persistence Schema:** Modernized `createSutramStore` initialization to utilize a `persistenceSchema` dictionary containing distinct `localSync` and `sessionSync` arrays, alongside `urlParser` mapping support. Legacy array fallbacks remain structurally intact.
* **Action Middleware Pipeline:** Exposed `registerActionMiddleware` via the `ExtensionRegistry` enabling UDF action interceptions prior to execution.
* **Gestural Scrub Tracks:** Extracted `yenvui-scrub-track` to normalize horizontal swiping, incorporating physics-driven layout adjustments aligned with paint cycles via `requestAnimationFrame`.
* **Asynchronous UX Improvements:** Applied loading states and animated spinners to `yenvui-dropdown`, mitigating friction during blocked async executions.
* **Component Primitives:** Separated strict synchronous execution into `<sutram-btn>` and mapped `variant` (solid, tinted) and `emphasis` layout tokens across the async variant stack.
