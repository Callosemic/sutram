## Description

* **Spatial Layout Engine & `LayoutStore`**: Added `LayoutStore` to `sutram/js/sdk.js` to support multi-column spatial viewports (`left`, `center`, `right`) with adaptive capacity calculations (1, 2, or 3 columns), focused column memory, mobile viewport index tracking, and column pinning/unpinning mechanics.
* **DOM Projection Engine (`SutramDOMPool` & `SutramProjectionCompiler`)**: Created `sutram/js/projection_engine.js` isolating layout slot compilation from DOM lifecycle management. Introduced `SutramDOMPool` to maintain non-destructive DOM node caching and event-driven eviction via `sutram-evict-projection`.
* **Universal Gesture Controller & Physics Engine**: Created `yenvui/js/physics.js` delivering `YenvuiGestureController` and `getDeepElementFromPoint` for Shadow DOM piercing hit detection, touch/pointer unification, long-press detection, and iOS Safari back-swipe prevention.
* **Spatial Drag Coordinator & Drop Targets**: Added `yenvui/js/drop-zone.js` (`<yenvui-drop-overlay>`, `<yenvui-drop-target>`) and `sutram/js/drag-coordinator.js` (`<sutram-drag-coordinator>`) enabling pointer-driven drag-and-drop reordering and column reassignment across spatial viewports.
* **Adaptive App Shell (`<sutram-app-shell>`)**: Refactored `sutram/js/app_shell.js` to render dynamic 3-column spatial tracks, desktop folder tabs, mobile centered pagination dots, global launcher dropdown panels, and smooth mobile snap transitions.
* **Consolidated Theme Mutation Observers**: Replaced individual `MutationObserver` instances in `yenvui/js/yenvui-base.js` and `sutram/js/sdk.js` (`SutramElement`) with shared `Set`-based theme subscriber registries (`subscribeToTheme` / `subscribeSutramToTheme`), reducing DOM observer overhead.
* **Presentation Primitives & Design Token Refinements**: Refined design tokens in `yenvui/css/theme-tokens.css` with deepened contrast values, translucent rail variables (`--rail-bg`, `--rail-hover`), updated `yenvui-card` grip rails with Lucide icon integration, `yenvui-search-bar` Lucide icons, `yenvui-collapsible` intent borders, and `html_desc` HTML rendering in `sutram-generic-settings`.
