## Description
Integrated standard form input Web Components, built a consumer UDF compliance static linter, extended Sutram and yenVUI presentation primitives with granular event controls, and introduced utility functions for file downloads and drag feedback.

### Key Changes Implemented
* **Standard Form Inputs (`sutram/js/inputs.js`)**: Added `SutramInput`, `SutramSelect`, `SutramTextarea`, and `SutramToggle` components supporting inline/stacked layouts and custom event dispatches (`sutram-input-changed`).
* **Consumer Compliance Linter (`tests/sutram_consumer_linter.py`)**: Implemented static analysis tool checking for UDF state isolation, raw DOM reads, metronome compliance, surgical DOM updates, CSS tokens, and module import constraints.
* **Primitive Component Enhancements (`sutram/js/primitives.js`)**:
  * `SutramAsyncBtn`: Added self-healing status reset logic upon `onClick`/`label` property updates.
  * `SutramCard`: Added configurable `selectionStoreKey`, `flush` padding mode, `_getStore()` store resolver, and `sutram-card-select-toggled` event dispatching.
  * Added `SutramFilterDropdown` presentation wrapper.
  * Forwarded component state changes (`sutram-collapsible-toggled`, `sutram-pill-toggled`, `sutram-filter-changed`) across collapsible panels, pills, and filter groups.
* **Extension Event Telemetry (`sutram/js/sdk.js`)**: Dispatched `sutram:extension-registered` custom event upon extension registration.
* **File & Drag Utilities (`sutram/js/utils.js`)**: Added `downloadBlob`, `downloadFile`, and `bindGhostDrag` for standardized file downloads and HTML5 drag ghost images.
* **yenVUI Chassis Refinements**:
  * `yenvui/js/card.js`: Added `flush` property and self-healing overlay reset on identity mutations.
  * `yenvui/js/collapsible.js`: Updated e-ink high-contrast border styling to dotted motif.
  * `yenvui/js/editor.js`: Disabled native spellcheck, autocorrect, and autocapitalize on CodeMirror input targets.
  * `yenvui/js/modal.js`: Added CSS token customization variables `--modal-backdrop` and `--modal-backdrop-filter`.
  * `yenvui/js/search-bar.js`: Implemented 250ms debouncing for search input events.
* **Documentation Map (`CODE_INDEX.md`)**: Updated index to include `inputs.js` and `sutram_consumer_linter.py`.
