## Description
* Implemented OS offline state yielding in `createJobPoller` (`sutram/js/poller.js`) by querying `window.Sutram.stores.Environment` to prevent network spam while disconnected.
* Added background job chaining support by intercepting `data.artifact.next_job_id` on completed jobs and automatically re-initiating the polling sequence for the chained task.
