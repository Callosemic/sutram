## Description
Refined the `<yenvui-card>` action tray overlay presentation and streamlined card gesture mechanics.

### Key Changes Implemented
* **Action Tray Frosted Backdrop (`yenvui/js/card.js`)**:
  * Added translucent backdrop styling using `color-mix(in srgb, ...)` with `backdrop-filter: blur(4px)` and `-webkit-backdrop-filter: blur(4px)` to action tray overlays in dark and light theme modes.
  * Explicitly disabled backdrop filters in E-Ink theme mode (`backdrop-filter: none`) to preserve high-contrast brutalist aesthetics.
  * Refined tray padding and action wrapper bottom padding to accommodate fine-pointer scrollbars.
* **Fine-Pointer Scrollbars (`yenvui/js/card.js`)**:
  * Added `@media (pointer: fine)` media query rules to render slim scrollbars on `.actions-wrapper` for mouse users without affecting touch devices.
* **Long-Press Event Cleanup (`yenvui/js/card.js`)**:
  * Removed legacy long-press pointer handlers (`_handlePointerDown`, `_handlePointerCancel`) and associated pointer down/up/move/cancel event listeners from `.card-wrapper` to streamline selection physics and rely strictly on edge-swipe and selection gutter interactions.

## Notes / Execution Log
All updates strictly maintain zero-bundler ES module standards, UDF state isolation, and presentation chassis compliance.
