## Description

* **Zero-CSS Lego Layout Primitives (`yenvui/js/layout.js`, `sutram/js/primitives.js`, `sutram/js/shared_styles.js`)**:
  - Implemented Layer 1 atomic presentation layout elements: `<yenvui-view>`, `<yenvui-stack>`, `<yenvui-surface>`, `<yenvui-action-bar>`, and `<yenvui-sidebar-layout>`.
  - Added Layer 2 pass-through definitions in `SutramUIAdapter.PASSTHROUGH_MAP` registering `<sutram-view>`, `<sutram-stack>`, `<sutram-surface>`, `<sutram-action-bar>`, and `<sutram-sidebar-layout>`.
  - Integrated responsive action bar collapse in `YenvuiActionBar` using `ResizeObserver` hysteresis, automatically collapsing child button labels to icon-only displays (`data-overflow`) when horizontal width is constrained.
  - Refactored `<sutram-categorized-list>`, `<sutram-folder-browser>`, `<sutram-selector-modal>`, `<sutram-settings-form>`, and `<sutram-report-projection>` to assemble their layouts using Lego primitives instead of custom CSS wrappers.
* **Chassis-Native Icon Primitive & Bootloader Cleanup (`yenvui/js/icon.js`, `sutram/js/primitives.js`, `sutram/js/sutram-boot.js`)**:
  - Created Layer 1 `<yenvui-icon>` and Layer 2 `<sutram-icon>` supporting semantic `size` (`xs`, `sm`, `md`, `lg`, `xl`) and `intent` tokens with CSS mask-image Data URI caching.
  - Removed legacy `<yv-icon>` class definition and CSS injection from `sutram-boot.js`.
  - Systematically migrated all presentation and shell templates across `app_shell.js`, `drag-coordinator.js`, `primitives.js`, `dropdown.js`, `card.js`, and `status-bar.js` to `<sutram-icon>` and `<yenvui-icon>`.
* **Semantic Tokenization & Presentational Property Deprecation (`yenvui/css/theme-tokens.css`, `tests/fitness/rules_yenvui.py`, `tests/sutram_consumer_linter.py`)**:
  - Deprecated presentational properties (`intentColor`, `maxWidth`, `minRows`, `maxHeight`, `borderless`, `bottomBorder`, `size="sm"`, `style="..."`) in favor of semantic tokens (`intent`, `size="compact|normal|wide|full"`, `columns="compact|normal|wide"`, `padding="none|xs|sm|md|lg"`, `?compact`, `?grow`, `?fullWidth`, `?flush`).
  - Parameterized `<yenvui-textarea>` around `_TEXTAREA_SIZE_PRESETS` and `variant="ghost"`.
  - Established structural geometry tokens in `theme-tokens.css` (`--yv-col-*`, `--yv-view-*`, `--yv-modal-*`, `--yv-surface-min-h-*`).
  - Added fitness and consumer lint rules: `YENVUI_SEMANTIC_PROPERTY_MANDATE`, `SUTRAM_INLINE_STYLE_BAN`, `SUTRAM_SEMANTIC_PROP_MANDATE`, `UNIFIED_SCALE_TOKEN_MANDATE`, `BANNED_YV_ICON_TAG_BAN`, and `PUBLIC_PROPERTY_ATTRIBUTE_NAME_MANDATE`.
* **Slash-Command Composer & Floating HUD Controls (`sutram/js/inputs.js`, `sutram/js/primitives.js`)**:
  - Implemented `<sutram-composer>` with slash-command absorption, typeahead search dropdown, trigger pill extraction, Backspace token clearing, and `@sutram-composer-submit` event routing.
  - Implemented `<sutram-floating-hud>` corner-pinned status and telemetry drawer with outside-click dismissal.
* **Multi-Column Window Constraints & Scope Preservation (`sutram/js/sutram_sdk.js`, `sutram/js/app_shell.js`)**:
  - Added `schema.preserveOnSwitch` to `createSutramStore` to preserve critical tenant-agnostic store slices across workspace switches.
  - Refactored `LayoutStore.openWindow` and `enforceWindowBounds` to calculate visible columns accurately across 2-column viewports (`left+center` or `center+right`).
  - Clamped single-column mobile viewports to a 1:1:1 normalized aspect ratio in `getSpatialMetrics` to prevent spatial track distortion.
* **ADR-0029 Editor Language Descriptors (`yenvui/js/editor.js`)**:
  - Implemented descriptor-based language loading (`{ url, kind: "lezer" | "stream" | "builtin", export, options }`) with `StreamLanguage.define()` wrapping, module-level promise caching, and plain-text fallback.
