## Description

* **Synchronous Batch Action Support**: Enhanced `<sutram-selection-tray>` (`sutram/js/primitives.js`) to support both `asyncAction` and synchronous `onClick` handlers for registered extension batch actions. Synchronous batch actions render as styled standard buttons with appropriate intent color contrast.
* **Native File Sharing Utility**: Added `nativeShareFiles` utility to `sutram/js/utils.js`. Provides Web Share API integration with MIME type hardening, text extension default fallbacks, garbage collection shielding via `window._lastSharePreserver`, and automatic timeout fallback cleanup.
