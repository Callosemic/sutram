## Description

* **Multi-Window Popout Architecture & BroadcastChannel IPC (`sutram/js/sutram_sdk.js`)**:
  * Implemented `canUseMultiWindowPopout()` gating multi-window capabilities on desktop browsers, excluding standalone PWAs and compact mobile viewports (`pointer: coarse` under 768px).
  * Established `_layoutBus` (`BroadcastChannel('sutram_layout_bus')`) coordinating cross-window presence and docking events.
  * Added `LayoutStore.popoutProjection` with user gesture preservation: synchronously calls `window.open('about:blank')` prior to resolving `sutram:before-popout` pre-save hooks, preventing popup blocker interception.
  * Added `LayoutStore.focusPopout` with double-click recall escape hatch (closing the popout and re-docking locally if activated twice within 3500ms).
  * Added `LayoutStore.dockInProjection` with presence ping/pong validation: docks back into the active host window via `dock_projection` message or self-heals by upgrading to the full workbench shell if the host is closed.
  * Added `pagehide` listeners in popout windows notifying the host via `popout_closed` broadcasts.
* **App Shell & Drag Coordinator Popout Integration (`sutram/js/app_shell.js`, `sutram/js/drag-coordinator.js`)**:
  * Routed drag-and-drop HUD popout actions directly through `LayoutStore.popoutProjection`.
  * Added capability check `LayoutStore.canPopout()` in `SutramDragCoordinator` to dynamically show or hide the popout drop target.
  * Expanded popout routing hash resolution in `SutramAppShell` to parse nested paths (`editor/<path>`).
* **Declarative Background Job Execution (`sutram/js/primitives.js`)**:
  * Integrated declarative background job dispatch into `SutramAsyncBtn` via `ExtensionRegistry.executeJobAction`, managing asynchronous progress, complete, and error lifecycle transitions with automatic status state machine updates.
* **Substrate Input Parity (`sutram/js/primitives.js`)**:
  * Standardized `SutramSelectorModal` by replacing raw `<input>` elements with declarative `<sutram-input>` components.
* **Tree Model Prefix Stripping & Path Tracking (`sutram/js/utils.js`)**:
  * Added `stripPrefix` normalization, explicit URI scheme handling (`vfs://`, `ws://`), and `treePath` segment preservation to `buildFileTree`.
* **Code Index Ledger Parity (`sutram/CODE_INDEX.md`)**:
  * Purged obsolete file references (`.gitignore`, `LICENSE`, `NOTICE`, `pyproject.toml`) and resolved missing ADR metadata.
